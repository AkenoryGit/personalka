# Тексты согласия и политики (шаг 2.6)

| Файл | Что | Где показывается |
| --- | --- | --- |
| [`consent.md`](consent.md) | Согласие на обработку персональных данных, варианты «Ребёнок» и «Взрослый» | Экран согласия в кабинете (6.1, шаг 2.12), отдельной карточкой |
| [`policy.md`](policy.md) | Политика обработки персональных данных | Отдельная страница сайта кабинета без токена — опубликована для всех (152-ФЗ, ст. 18.1); ссылка с экрана согласия и из подвала кабинета |

**Статус:** редакция 1 согласована Дмитрием 24.10.2026, дата редакции — 24.10.2026 (запуск кабинетов, шаг 2.12). На шаге 2.12 из «Что тренер делает с данными» убраны слова «а бумажное согласие — вручную»: бумажного согласия нет (решение Дмитрия 24.10.2026). На сервере тексты — `LegalText` в `shared/domain/.../format`; правка здесь переносится туда.

## Что подставляет сервер

| Поле | Откуда |
| --- | --- |
| `{Фамилия Имя Отчество тренера}` | Профиль тренера (3.2), полностью |
| `{контакт для обращений}` | Контакт тренера для родителей (3.2) — телефон или почта |
| `{Фамилия Имя клиента}` | Карточка клиента, без склонения (как в шапке кабинета) |
| `{дата редакции}` | Дата редакции текста в виде «22.10.2026» (10.6) |
| `{адрес политики}` | Адрес страницы политики этого тренера: `/policy/<id тренера>` |

Оператор — каждый тренер сам, поэтому и политика у каждого своя: тот же текст со своими ФИО и контактом.

## Версии

- Номер редакции записывается в ConsentRecord (`text_version`, 3.7).
- Правка слов без новых целей и данных — новая редакция, согласие заново не спрашивается.
- Новые цели или новые данные — новая редакция, и экран согласия показывается снова (3.7).
