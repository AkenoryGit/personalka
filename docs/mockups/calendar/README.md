У каждого макета есть переключатель темы (`dark` во вкладке Tweaks). Клиенты и расписание придуманы; реальные имена в макеты не попадают.

## Решения (внесены в ТЗ 3.2, 5.3, 5.16)

- **Часы сетки:** клуб работает 07:00–23:00, это значение по умолчанию у `work_day_start` / `work_day_end` (было 07:00 / 22:00). Ночь не показывается. Тренировка вне часов (бывают старты в 06:30–06:45) не запрещена: сетка таких дней расширяется до её полного часа, создать её можно через «+» с любым временем.
- **Прокрутка при открытии:** к «сейчас − 1 час», но не дальше конца часов работы; в 15:40 на сложенном Fold виден 11:00–23:00.
- **Строки блока по высоте:** от 56 dp — имя, время, тип · место; 40–56 dp — имя и «начало · место»; меньше 40 dp — имя и начало одной строкой. Причина: при часе 64 dp тренировка на 50 минут — это 53 dp, и по прежней таблице место (ББ / ДБ) на ней не показывалось; а две строки текста 13/16 физически не помещаются в 28 dp.
- **Строка недели** пн–вс под шапкой в виде «День»; сегодняшнее число — в оранжевом кружке.
- **Месяц:** число — тренировки без отменённых; до четырёх точек — самые частые типы дня; под сеткой — список выбранного дня.
- **Полоска запрета** — штриховка цветом `outline` (3,6 : 1 в светлой, 3,5 : 1 в тёмной), а не `hatch` (2,2 : 1 и 2,9 : 1 — ниже порога 3 : 1 для графики). Штриховка самой зоны остаётся `hatch`.
- Отмена со списанием на блоке — как отменённая (серый фон, зачёркнуто) плюс значок ₽.
- В виде «несколько дней» линия «сейчас» и приглушение прошлого — только в колонке сегодняшнего дня.
- **Шаг 1.10 (ТЗ 5.3):** окно «Нажатие на запрет» в приложении — по центру экрана, как список «+N», а не нижняя панель: оно переживает сложение Fold. «Изменить» появится с формой запрета (1.13), до тех пор в окне только «Пропустить этот день».

## Проверка

Все макеты отрисованы локально в обеих темах. Новые пары цветов: сланцевый текст на заливке дежурства 6,5 : 1 / 8,0 : 1; подписи часов на фоне прошедшего 5,1 : 1 / 5,8 : 1. Полоса дежурства на его заливке — 2,95 : 1 в светлой теме (на грани), к фону сетки — 3,7 : 1; в тёмной 4,3 : 1 и 6,1 : 1.
