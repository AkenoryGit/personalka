# Оформление «Персоналки» (шаг 0.2)

Решено 18.10.2026. Дизайн-система с живыми образцами в обеих темах: https://claude.ai/artifact/4UJFh5unXsK26uByWtP24k — опора для макетов 0.3–0.8.

## Решения

- **Основа:** Material 3 со своей палитрой. Светлая тема — кремовый лист и графит, тёмная — графит и кремовый, как иконка.
- **Основной цвет** `primary` — графит #15171A в светлой теме, кремовый #F3EFE6 в тёмной. Им залита одна главная кнопка экрана, выбранный чип, включённый переключатель, кольцо фокуса.
- **Фирменный оранжевый** #FF5A1F означает «сейчас» и «сделать» и стоит ровно в пяти местах: кнопка «+», кружок сегодняшнего числа, счётчик дел на «Главной», линия текущего времени, точка «нет дневника». Текст на оранжевом — только графитовый (5,8:1); белый даёт 3,1:1.
- **«Поверх запрета» — фиолетовый**, а не оранжевый. Тёплые цвета уже заняты: оранжевый — фирменный, янтарный — «со списанием», красный — ошибки. Фиолетовый отличается от фирменного оранжевого на ΔE 27–33 (порог заметной разницы — около 2), значок — треугольник.
- **Линия «сейчас» — фирменная оранжевая**, а не красная (ТЗ 5.3 изменён). В тёмной теме красный ошибки и оранжевый почти сливались бы в шапке календаря; так красный остаётся только для ошибок.
- **Отменённые блоки** — фиксированные цвета (фон `surface-alt`, текст `text-muted` зачёркнутый) вместо прозрачности 60 %: при 60 % текст опускался ниже 4,5:1 и нарушал ТЗ 10.4.
- **Блоки календаря** обведены зазором 1 dp цвета фона сетки — наложенные блоки и блоки поверх дежурства не сливаются. Значки на блоке сидят в кружке 16 dp цвета фона, поэтому видны на блоке любого цвета. «Приглушение» прошедшего времени касается только фона сетки.
- **Шрифт** системный (Roboto / SF): 22, 17, 15, 13 sp, плюс 28 sp только для суммы «Заработано» на карточке «Деньги». Начертания 400 и 500. Цифры времени и сумм — моноширинные (`tnum`).
- **Сетка:** отступы кратны 4 dp, поля 16, нажатие не меньше 48 × 48; скругления: блок 6, чип 8, карточка/кнопка/поле 12, «+» 16, нижняя панель 20.
- **Цвет типа хранится ключом** палитры (`blue`, `green`…), а не ARGB: у каждой темы свои тона. ТЗ 3.3 изменён.
- **Типы по умолчанию:** ПТ — синий, Сплит — индиго, Мини-группа — салатовый, Группа — зелёный, СПТ — розовый, Дежурство — сланцевый, Грудничковое — бирюзовый, Гидрореабилитация — пурпурный, Кинезио — коричневый.

## Контраст

Скрипт проверил 178 пар «цвет — фон» в обеих темах, все проходят: текст не ниже 4,5:1, полосы, точки, рамки и значки не ниже 3:1. Главные пары:

| Пара | Светлая | Тёмная |
| --- | --- | --- |
| Основной текст на surface-alt | 14,4 | 12,1 |
| Второстепенный текст на surface-alt (худшая пара) | 4,6 | 4,6 |
| Надпись главной кнопки | 15,6 | 15,6 |
| Значок «+», число «сегодня» на оранжевом | 5,8 | 5,8 |
| Оранжевый текст на surface-alt | 4,6 | 4,6 |
| «Проведено» текстом на surface-alt | 4,6 | 5,4 |
| «Со списанием» текстом на surface-alt | 4,6 | 5,1 |
| «Поверх запрета» текстом на surface-alt | 4,6 | 4,9 |
| Ошибка текстом на surface-alt | 4,6 | 4,8 |
| Метка «Со списанием» | 6,9 | 8,6 |
