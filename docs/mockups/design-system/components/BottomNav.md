# BottomNav

Нижняя панель из пяти разделов на обычном и сложенном экране.

Высота `size-nav-bar` 72, фон `surface`, сверху линия `divider`. Разделы: Главная, Календарь, Клиенты, Зарплата, Ещё (ТЗ 5.1).
Выбранный раздел: значок залит, под ним плашка 56 × 32 `surface-alt`, подпись `caption-strong` `text`. Остальные — контурный значок и подпись `text-muted`.
Счётчик дел на «Главной» — `accent` с цифрами `on-accent`; больше 99 — «99+». На разложенном Fold те же разделы стоят боковой панелью слева.
