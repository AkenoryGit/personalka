# Button

Кнопка выполняет одно действие и называет его глаголом.

- **Главная** (`primary` / `on-primary`) — одна на экран или панель: «Проведено», «Сохранить», «Отменить тренировку».
- **Вторая** (`surface-alt` / `text`) — частое, но не главное действие: «Дневник».
- **Контурная** (рамка `outline`) — редкие действия рядом с главной: «Изменить».
- **Текстовая** — самые тихие действия: «Отменить» в панели, «Пропустить».
- **Опасная** (рамка и текст `error`) — только необратимое: «Удалить клиента полностью». Перед ней всегда подтверждение.
- **Недоступная** — `surface-alt` и `text-muted` (4,6 : 1), с подсказкой рядом, почему нельзя.

Высота `size-button` 48, скругление `radius-card`, надпись `body-strong`, значок 20 dp слева — по желанию. Оранжевых кнопок нет: оранжевый — только «+».
Передаётся: надпись, вид, значок, обработчик нажатия, доступность.
