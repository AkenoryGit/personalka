# CalendarBlock

Блок тренировки в календаре: фон и полоса цвета типа, имя, время, значки статуса.

Фон `type-<цвет>-block`, полоса 3 dp `type-<цвет>-stripe`, текст `type-<цвет>-text`, скругление `radius-block`, зазор 1 dp цвета `surface` вокруг. Содержимое по высоте (ТЗ 5.3):
- от 56 dp — имя, время, «тип · место»;
- 40–56 dp — имя и «начало · место»;
- меньше 40 dp — имя и начало одной строкой, лишнее — многоточием.

Имя — `caption-strong`, остальное — `caption` с моноширинными цифрами. Значки — в правом верхнем углу, в кружках `size-badge` цвета `surface`: ниже 56 dp один, выше — до двух, по важности ₽ → треугольник → точка → «слои» → галочка.
Отменённый: фон `surface-alt`, полоса `outline`, текст `text-muted` зачёркнутый; показ отменённых выключается в настройках календаря.
Перетаскиваемый: тень `shadow-drag`, масштаб 1,02, над пальцем подсказка `inverse-surface` / `inverse-text` с датой и временем; на старом месте — пунктирный призрак `outline`.
Передаётся: имя, время, тип с цветом, место, статус и флаги (со списанием, поверх запрета, нет дневника, поверх дежурства), высота.
