# Card

Карточка собирает один блок информации на «Главной» и в карточках клиента и тренировки.

Фон `surface` на `bg`, скругление `radius-card`, внутренний отступ `space-4`, между карточками `space-6`. Ни тени, ни рамки.
Верхняя строка — `caption` `text-muted` (что это за блок), ниже — главное значение: `title` для времени, `number` для суммы. Кнопки — внизу, главная слева.
Полоса выполнения плана — дорожка `surface-alt` высотой 8, заливка `primary`; оранжевый здесь не используется.
Карточка «Ближайшая тренировка» и карточка «Деньги» — образцы для главной (ТЗ 5.2).
