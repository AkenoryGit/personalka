# Chip

Чип выбирает один вариант из короткого списка: тип, место, длительность, причину отмены.

Высота `size-chip` 36 (зона нажатия 48), скругление `radius-chip`, надпись `caption-strong`, промежуток `space-2`.
- Невыбранный — `surface-alt` / `text`.
- Выбранный — `primary` / `on-primary` с галочкой слева.
- Чип типа тренировки показывает точку цвета `type-<цвет>-stripe` 8 dp, пока не выбран; выбранный показывает галочку, цвет типа остаётся в точке у остальных.
Последний использованный вариант стоит первым (ТЗ 5.5). Больше 7 вариантов — уже список, а не чипы.
Передаётся: надпись, выбран или нет, цвет точки (для типов), обработчик.
