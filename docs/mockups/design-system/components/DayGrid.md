# DayGrid

Колонка дня в календаре со всеми слоями: прошедшее время, дежурство, запрет, тренировки, наложения и линия «сейчас».

Колонка времени `size-time-column` 48, подписи часов — `caption` `text-muted` с моноширинными цифрами. Час — `size-hour` 64. Линии часов — 1 dp `divider`, получасовые — пунктир `divider`.
Слои снизу вверх: `surface` → `past-tint` до текущего времени → дежурство (`duty-fill` и сплошная полоска 4 dp) → запрет (штриховка `hatch` 45°, линии 1,5 dp через 8 dp, штрихованная полоска 4 dp) → линии → тренировки → линия `now` 2 dp с точкой 8 dp.
Наложения делят ширину колонки поровну; минимальная ширина блока 36 dp, больше четырёх колонок — три и метка «+N».
Шапка дня: день недели `caption` `text-muted`, число `subtitle`; сегодняшнее число — в кружке `accent` цифрами `on-accent`.
Нажатие на полоску зоны показывает её: «ДБ 17:00–18:30 — групповая тренировка» с кнопками «Изменить» и «Пропустить этот день».
