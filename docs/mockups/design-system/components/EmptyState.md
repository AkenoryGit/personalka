# EmptyState

Пустой экран объясняет, что здесь будет, и предлагает первое действие.

Круг 64 `surface-alt` со значком 28 `text-muted`, заголовок `subtitle`, пояснение `body` `text-muted` не длиннее двух строк, главная кнопка с глаголом (ТЗ 5.20).
Не используется для ошибок: для них — текст ошибки и способ исправить.
