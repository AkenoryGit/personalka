# Fab

Кнопка «+» создаёт новую тренировку и есть только на «Главной» и в «Календаре».

Заливка `accent`, значок «+» цвета `on-accent` (5,8 : 1), размер `size-fab` 56, скругление `radius-fab` 16, тень `shadow-raised`. Стоит в правом нижнем углу над нижней панелью, отступ 16 dp от краёв. Подпись для TalkBack — «Новая тренировка».
Одна на экран. Не меняет цвет и не превращается в другие действия: если нужно другое действие, это обычная кнопка.
