# ListRow

Строка списка клиентов: имя, короткое расписание и дата ближайшей тренировки.

Высота `size-row` 64, отступы `space-4`, разделитель `divider` с отступом 16 слева. Имя — `body-strong`, вторая строка — `caption` `text-muted`, справа — дата `caption` с моноширинными цифрами.
В списке «Без записи» вторая строка — последнее посещение («был вт 15.10, ПТ ББ»), а пометки «после СПТ» и «писали 18.10» — маленькие метки `surface-alt` / `text-muted` высотой 22.
Нажатие на строку открывает карточку клиента.
