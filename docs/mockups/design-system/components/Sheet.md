# Sheet

Нижняя панель показывает карточку тренировки поверх календаря.

Фон `surface`, верхние углы `radius-sheet`, тень `shadow-sheet`, под ней — затемнение `scrim`. Сверху ручка 32 × 4 цвета `outline`. На разложенном Fold та же карточка открывается справа, без затемнения.
Шапка: имя — `subtitle`, строка «дата · время · тип · место · серия» — `caption` `text-muted`. Предупреждения — метками статуса во всю ширину с текстом причины. Ниже — план, оплата, затем кнопки: главная слева.
