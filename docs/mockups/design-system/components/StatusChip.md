# StatusChip

Метка статуса тренировки или участия: значок и слово на цветной подложке.

Высота 28, скругление `radius-chip`, значок 16 dp, надпись `caption-strong`. Пары цветов — из таблицы статусов в разделе «Цвет»: `<статус>-container` / `on-<статус>-container`. «Запланировано» — без заливки, рамка `outline`.
Где: история тренировок в карточке клиента, карточка тренировки, кабинет родителя (без «Поверх запрета» и «Нет ставки» — они только для тренера).
Слово обязательно: метка без слова не используется, даже если места мало.
