# TextField

Поле ввода с подписью над ним; ошибка показывается под полем словами.

Высота однострочного поля `size-field` 56, скругление `radius-card`, фон `surface`, рамка 1 dp `outline`. В фокусе — рамка 2 dp `primary`. Ошибка — рамка `error` и строка под полем: значок и текст `error`, что не так и как исправить («Не больше 600 минут»).
Подпись над полем — `caption-strong` `text-muted`, значение — `body` `text`, подсказка внутри — `text-muted`. Подсказка под полем — `caption` `text-muted`.
Поле дневника растёт по тексту, справа — микрофон для голосового ввода. Под полями дневника подсказка «Без диагнозов и сведений о здоровье», у группы — «Видят родители всех детей — не пишите имён» (ТЗ 5.7).
