# Toggles

Переключатель включает настройку сразу, флажок отмечает пункт, который сохранится кнопкой.

- **Переключатель** — для настроек, которые действуют сразу: «Вести дневник», «Вечерняя сводка». Включён: дорожка `primary`, кружок `on-primary`. Выключен: дорожка `surface-alt` с рамкой `outline`, кружок `outline`. Размер 52 × 32.
- **Флажок** — внутри формы, которая сохраняется кнопкой: «Считать как ПТ», поля дневника у типа. Отмечен: `primary` с галочкой `on-primary`; пустой — рамка 2 dp `outline`. Размер 20, скругление 4.
Нажимается вся строка с подписью, высота строки 56. Подпись — `body`, пояснение под ней — `caption` `text-muted`.
