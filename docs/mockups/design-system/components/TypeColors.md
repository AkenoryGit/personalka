# TypeColors

Палитра из 16 цветов, из которой тренер выбирает цвет типа тренировки.

Последний шаг конструктора типа (ТЗ 5.16). Плитка показывает блок так, как он будет выглядеть в календаре; выбранная обведена кольцом `primary` 2 dp с отступом 2 dp. Под плиткой — ключ цвета, по нему берутся токены `type-<ключ>-block`, `-stripe`, `-text`.
Цвет типа — подсказка, а не единственный признак: в блоке всегда есть название клиента или группы, в карточке — название типа.
Два типа одного цвета разрешены (например, два вида групп), но приложение предупреждает: «Этот цвет уже у типа „Группа“».
