**Отличие Android от макета:** время — часами («до 11:50», «в 07:00»), а не «до конца 26 мин»: виджеты Android не обновляются каждую минуту (ТЗ 5.2, «Виджеты»). На iPhone отсчёт минут система ведёт сама — там он останется.
