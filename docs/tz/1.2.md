# 1.2. Пользователи и роли

Раздел [1. Общие сведения](1.md) · [оглавление ТЗ](README.md)

| Роль | Кто | Через что | Права |
| --- | --- | --- | --- |
| Тренер | Тренер клуба (первый — Дмитрий) | Мобильное приложение | Все действия со своими данными; чтение общих данных клуба |
| Администратор системы | Дмитрий | Приложение (раздел «Клуб») и сервер | Тренер + учётные записи тренеров, общие данные клуба (места, запреты, сетка ставок, ступени), разовый импорт |
| Родитель или взрослый клиент | Получатель ссылки | Браузер | Только просмотр данных одного клиента |

Клиенты приложение не устанавливают и учётных записей не имеют.
