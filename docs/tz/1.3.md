# 1.3. Глоссарий

Раздел [1. Общие сведения](1.md) · [оглавление ТЗ](README.md)

| Термин | Значение |
| --- | --- |
| ПТ | Персональная тренировка, один клиент |
| Сплит | Тренировка для двух клиентов, оплачивается целиком, в счётчике ПТ = 1 |
| Мини-группа, группа | Групповые тренировки, оплата за каждого пришедшего |
| СПТ | Стартовая (пробная) персональная тренировка |
| Закрытая СПТ | СПТ, после которой клиент в течение месяца купил блок со скидкой |
| ББ / ДБ | Большой / детский (малый) бассейн |
| Место | Бассейн, зал или другое помещение |
| Тип тренировки | Настраиваемый вид: ПТ, сплит, группа, СПТ, дежурство и т. д. |
| Запрет | Отрезок времени, когда в месте нежелательно ставить тренировки; даёт предупреждение, не запрет |
| Дежурство | Оплачиваемое время работы в бассейне, 200 ₽/ч |
| Серия | Постоянное расписание: тренировка, повторяющаяся по дням недели |
| Лист ожидания | Клиенты, которым нужно постоянное или разовое время, а оно занято; приложение показывает, когда такое время освободилось (4.16) |
| Владелец группы | Тренер, на котором группа числится в 1С |
| Коллега | Другой тренер, с которым ведутся совместные группы или бывают замены |
| Ступень | Уровень ставок по числу ПТ за месяц: 1–100, 101–150, 151+ |
| Заработано | Честная доля тренера до налога; используется для плана |
| Начислено клубом | Сумма, которую клуб начисляет тренеру (с неё считается налог) |
| На руки | Деньги, которые тренер реально получит: карта + наличные ± взаиморасчёты |
| Кабинет | Веб-страница одного клиента для родителя или самого клиента |
