# 1.5. Режимы работы

Раздел [1. Общие сведения](1.md) · [оглавление ТЗ](README.md)

У каждого тренера один из двух режимов. В обоих полная копия данных хранится в телефоне, поэтому падение или отключение сервера не приводит к потере данных — перестают работать только кабинеты родителей.

| Режим | Где данные | Учётная запись | Что доступно | Как включить |
| --- | --- | --- | --- | --- |
| Только телефон (по умолчанию) | Только в телефоне | Не нужна | Всё, кроме кабинетов и синхронизации между устройствами | Сразу после установки |
| С сервером | В телефоне + копия на сервере | Нужна | Всё, включая кабинеты и несколько устройств | Только по приглашению администратора |

- **Включение сервера.** Администратор создаёт одноразовый код приглашения (действует 7 дней). Тренер вводит код, имя, почту и пароль → создаётся учётная запись → все данные телефона выгружаются → дальше идёт синхронизация.
- **Отключение сервера.** Тренер подтверждает → кабинеты его клиентов сразу перестают открываться → его данные на сервере удаляются в течение 24 часов → в телефоне всё остаётся.
- **Приостановка администратором.** Администратор может приостановить доступ тренера: кабинеты выключаются, синхронизация останавливается, данные в телефоне тренера не трогаются.
- **Адрес сервера** задаётся в настройках (по умолчанию — домен Дмитрия). Переезд на другой сервер не требует новой версии приложения.
- **Резервная копия в режиме «Только телефон»** — автоматический файл в выбранную тренером папку (раздел 7.7). Без неё потеря телефона = потеря данных; приложение напоминает, если копии нет больше 7 дней.
- **Условия сервера** показываются при подключении: сервер работает без гарантий доступности; согласия родителей на обработку данных собирает тренер. Тренер подтверждает галочкой.
- **Порядок появления.** На этапах 2–4 сервером пользуется только Дмитрий: его учётная запись создаётся командой на сервере. Приглашения, приостановка и раздел «Клуб» появляются на этапе 5. Модель данных с первого дня рассчитана на нескольких тренеров, поэтому потом ничего не переделывается.
