# 10.1. Скорость и объёмы

Раздел [10. Нефункциональные требования](10.md) · [оглавление ТЗ](README.md)

| Показатель | Требование |
| --- | --- |
| Холодный запуск до календаря | до 1,5 с на Z Fold 8; до 3 с на телефоне среднего уровня 2021 года |
| Открытие любого экрана | до 300 мс |
| Прокрутка и перетаскивание | 60 кадров в секунду |
| Пересчёт месяца | до 100 мс |
| Синхронизация 100 изменений | до 3 с на 4G |
| Объём данных тренера | до 200 активных клиентов и 15 000 тренировок в год без замедления |
| Сервер | до 30 тренеров на текущем VPS |
| Размер установочного файла | до 30 МБ |
| Фоновая работа | не чаще раза в 15 минут и только при наличии сети |
