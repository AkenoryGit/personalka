# 10.4. Доступность

Раздел [10. Нефункциональные требования](10.md) · [оглавление ТЗ](README.md)

- Нажимаемые элементы не меньше 48 × 48 dp.
- Вёрстка не ломается при системном размере шрифта до 130%.
- Контраст текста не ниже 4,5 : 1 в обеих темах.
- Статус никогда не передаётся только цветом — всегда есть значок или слово.
- Основные элементы подписаны для чтения с экрана (TalkBack / VoiceOver).
