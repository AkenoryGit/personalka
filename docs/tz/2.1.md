# 2.1. Компоненты

Раздел [2. Архитектура и технологии](2.md) · [оглавление ТЗ](README.md)

| Компонент | Технология | Назначение |
| --- | --- | --- |
| Приложение тренера | Kotlin Multiplatform, Compose Multiplatform | Все экраны и логика; Android — этапы 1–4, iPhone — этап 5 |
| Локальная база | Room KMP (SQLite) | Все данные тренера; миграции схемы по версиям |
| Фоновые задачи | WorkManager (Android), BGTaskScheduler (iOS) | Синхронизация, продление серий, напоминания, автокопия |
| Сеть | Ktor Client, kotlinx.serialization | Обмен с сервером |
| Даты и время | kotlinx-datetime | Часовой пояс клуба Asia/Yekaterinburg |
| Внедрение зависимостей | Koin | — |
| Сервер | Kotlin, Ktor 3.1.3, Java 21, systemd | API, синхронизация, кабинеты, фоновые задачи |
| База сервера | PostgreSQL 16, миграции Flyway | Копии данных тренеров в режиме «С сервером» |
| Кабинет родителей | Серверная вёрстка kotlinx.html, графики SVG на сервере | Страницы без внешних скриптов и счётчиков |
| HTTPS | Caddy, Let's Encrypt | Свой поддомен |
| Разбор PDF из 1С | PdfBox-Android (Android), PDFKit (iOS) через expect/actual | На телефоне, работает в обоих режимах |
| Импорт таблиц | Отдельная утилита JVM + Apache POI | Разовый запуск, в приложении не видна |
| Выкладка | GitHub Actions по SSH, откат на предыдущую версию | Как у Planovo |
