# 2. Архитектура и технологии

[Оглавление ТЗ](README.md)

Приложение строится по принципу «сначала телефон»: все данные и вся логика живут на устройстве, сервер хранит копию, синхронизирует устройства и отдаёт кабинеты. Стек повторяет Planovo.
