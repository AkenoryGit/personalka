# 3.1. Общие правила

Раздел [3. Модель данных](3.md) · [оглавление ТЗ](README.md)

- **Идентификаторы** — UUID v7, создаётся на устройстве. Сервер идентификаторы не меняет.
- **Служебные поля у каждой записи:** `coach_id`, `created_at`, `updated_at` (момент UTC), `version` (целое, +1 при каждом изменении), `deleted_at` (признак удаления для синхронизации).
- **Удаление** мягкое: запись помечается `deleted_at` и физически стирается через 90 дней. Исключение — «Удалить клиента полностью»: данные клиента стираются сразу и с сервера (право на удаление по 152-ФЗ); зарплатные итоги прошлых месяцев при этом сохраняются без имени.
- **Деньги** — целые копейки (Long). **Доли** (доля официальной части, ставка НДФЛ) — целые десятитысячные: 0,5 = 5000, 0,13 = 1300. **Длительности** — минуты. **Время тренировок** — локальные дата и время в часовом поясе клуба; служебные моменты — UTC.
- **Перечисления** хранятся строками (`PLANNED`, `DONE`…), не числами.
- **Версии по датам.** Ставки, категория, схема выплат и ступени хранятся версиями с `valid_from`. Версия действует с этой даты до следующей версии. Изменение всегда создаёт новую версию; правка старой — только с предупреждением «пересчитаются прошлые месяцы».
- **Область данных** (`scope`): `COACH` — данные одного тренера; `CLUB` — общие данные клуба (места, запреты, сетка ставок, ступени). Данные клуба правит только администратор; в режиме «С сервером» они приходят всем тренерам клуба, в режиме «Только телефон» — импортируются файлом «Шаблон клуба».
