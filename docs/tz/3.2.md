# 3.2. Тренер и настройки

Раздел [3. Модель данных](3.md) · [оглавление ТЗ](README.md)

**Coach — тренер**

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | UUID | Создаётся при первом запуске |
| `last_name`, `first_name`, `middle_name` | String, String, String? | ФИО тренера. Вводится при первом запуске (5.18), меняется в «Профиле». В шапке кабинета — имя и фамилия («Дмитрий Дудник»), в согласии оператор данных — полностью («Дудник Дмитрий Викторович»). Отчества может не быть |
| `contact_for_parents` | String? | Телефон или почта для обращений родителей: подставляется в согласие и политику обработки. Спрашивается при включении кабинетов; без него кабинеты не включаются |
| `name_1c` | String? | ФИО тренера в заголовке отчёта 1С — для проверки, что отчёт свой |
| `mode` | `LOCAL` / `SERVER` | Режим работы (раздел 1.5) |
| `role` | `COACH` / `ADMIN` | Роль на сервере |
| `server_url` | String? | Адрес сервера |
| `email` | String? | Логин (только `SERVER`) |
| `timezone` | String | По умолчанию `Asia/Yekaterinburg` |

**CoachSettings — настройки тренера** (одна запись на тренера)

| Поле | По умолчанию | Описание |
| --- | --- | --- |
| `cancel_notice_minutes` | 60 | Меньше этого до начала — отмена со списанием |
| `diary_enabled` | true | Вести дневник |
| `digest_enabled` / `digest_time` | true / 21:00 | Вечерняя сводка (5.19) |
| `instant_diary` / `instant_group` | false / false | Мгновенные напоминания через 15 мин после конца о дневнике и об отметке группы (5.19) |
| `followup_enabled` / `followup_days` | true / 14 | Список «Без записи» и пункт в вечерней сводке (4.15) |
| `cabinets_enabled` | false | Общий выключатель кабинетов (только `SERVER`) |
| `co_coaching_enabled` | false | Совместное ведение групп и замены |
| `work_day_start` / `work_day_end` | 07:00 / 23:00 | Часы сетки календаря (по умолчанию — часы клуба) и рамки поиска слотов. Тренировку вне них ставить можно: сетка таких дней расширяется до её часа (5.3) |
| `drag_step_minutes` | 15 | Шаг при перетаскивании: 5, 10, 15, 30 |
| `series_horizon_weeks` | 8 | На сколько недель вперёд создавать тренировки из серий |
| `upcoming_in_card` | 4 | Сколько ближайших тренировок показывать в карточке и кабинете |
| `auto_done_personal` | true | Персональные без отмены становятся «Проведено» в момент окончания |
| `week_view_days` | 3 | Дней в разложенном виде: 3, 5 или 7 |
| `backup_folder_uri` | — | Папка автокопии (выбирается системным диалогом) |
| `backup_frequency` | `DAILY` | `OFF` / `DAILY` / `WEEKLY` |

**CategoryVersion — категория тренера:** `valid_from` (Date), `category` (`TRAINER` — персональный тренер / `MASTER` / `ELITE`).

**PaySchemeVersion — схема выплат**

| Поле | Тип | Описание |
| --- | --- | --- |
| `valid_from` | Date | С какого месяца действует (всегда 1-е число) |
| `kind` | `HALF_OFFICIAL` / `FULL_OFFICIAL` / `IP` / `NONE` | Тип схемы |
| `official_share` | Decimal | Доля официальной части: 0,5 / 1 / 0 / 0 |
| `ndfl_rate` | Decimal | 0,13 для официальной части |
| `advance_day` | Int? | 25; нет для `IP` и `NONE` |
| `advance_default` | Money? | Ожидаемый аванс, например 13 546,50 ₽ |
| `salary_day` | Int | 10 — день выплаты за прошлый месяц |

У Дмитрия: с 01.01.2026 — `NONE`, с 01.03.2026 — `HALF_OFFICIAL`.
