# 3.4. Расписание

Раздел [3. Модель данных](3.md) · [оглавление ТЗ](README.md)

**ScheduleBlock — запрет** (дежурства — это тренировки типа `DUTY`, см. Training)

| Поле | Тип | Описание |
| --- | --- | --- |
| `scope` | `COACH` / `CLUB` | Личный или общий для клуба |
| `location_id` | UUID | Где действует |
| `reason` | String | Текст предупреждения: «Групповая тренировка (Иванова)» |
| `weekdays` | Set? | Дни недели для повторяющегося; пусто для разового |
| `date` | Date? | Дата разового |
| `start_time`, `end_time` | Time | Отрезок внутри дня |
| `valid_from`, `valid_to` | Date, Date? | Период действия повторения |
| `skip_dates` | List of Date | Исключённые даты («в эту субботу группы нет») |

**Series — постоянное расписание**

| Поле | Тип | Описание |
| --- | --- | --- |
| `type_id`, `location_id` | UUID | Что и где |
| `client_ids` | List of UUID | Клиенты для ПТ/сплита/СПТ (таблица SeriesClient) |
| `group_id` | UUID? | Для групповых |
| `weekdays` | Set | Дни недели |
| `start_time`, `duration_min` | Time, Int | Время и длительность |
| `valid_from`, `valid_to` | Date, Date? | Период серии; пустой `valid_to` = бессрочно |
| `generated_until` | Date | До какой даты уже созданы тренировки |

Ещё у серии: `skip_dates` — даты, на которых серия не создаёт тренировку (раздел 4.4): пропущенные («Пропустить дату», «Отпуск») и даты тренировок, изменённых «Только эту», — их место уже занято своей тренировкой.
