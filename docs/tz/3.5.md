# 3.5. Клиенты, группы, тренировки

Раздел [3. Модель данных](3.md) · [оглавление ТЗ](README.md)

**Client — клиент**

| Поле | Тип | Описание |
| --- | --- | --- |
| `last_name`, `first_name`, `middle_name` | String, String, String? | ФИО; поиск по любой части |
| `birth_date` | Date? | Возраст считается на сегодня |
| `is_adult` | Boolean | Автоматически true при возрасте 18+, иначе задаётся вручную |
| sex | MALE / FEMALE? | Пол, необязателен. Предлагается по отчеству или фамилии и задаётся родственной связью (4.17). Нужен для слов «отец / мать», «был / была» (10.6); в кабинет не передаётся |
| `contact_name`, `contact_phone` | String? | Телефон для связи («Позвонить») и кому отправлять ссылку на кабинет (необязательно) |
| `media_url` | URL? | Ссылка на фото и видео (Яндекс Диск, Облако Mail.ru …) |
| `private_note` | String? | Внутренняя заметка; никогда не передаётся в кабинет |
| `name_1c` | String? | ФИО как в 1С (заполняется при первой сверке) |
| `cabinet_enabled` | Boolean | Кабинет для этого клиента |
| `consent_at` | DateTime? | Когда получено согласие: родитель отметил его в кабинете или тренер отметил бумажное (6.1). Без согласия кабинет показывает только экран согласия |
| `consent_source` | `CABINET` / `PAPER`? | Как получено согласие: галочкой в кабинете или на бумаге |
| `followup_contacted_at`, `followup_paused_until`, `followup_pause_note` | DateTime?, Date?, String? | «Написал» и «Пауза до…» для списка «Без записи» (4.15); в кабинет не передаются |
| `pending_plan` | String? | План, которому не нашлось следующей тренировки (раздел 4.3) |
| `status` | `ACTIVE` / `ARCHIVED` | В архиве — ушёл, история сохраняется, серии закрываются |
| `source` | `MANUAL` / `IMPORT` | Откуда запись |

**Group — постоянная группа**

| Поле | Тип | Описание |
| --- | --- | --- |
| `name` | String | «Сб 9:00 ББ» |
| `type_id`, `location_id` | UUID | Тип (`GROUP`) и место |
| `owner` | `SELF` / `COLLEAGUE` | На ком числится в 1С |
| `owner_colleague_id` | UUID? | Если на коллеге |
| `default_conducted_by` | `SELF` / `SELF_AND_COLLEAGUE` / `COLLEAGUE` | Кто обычно ведёт |
| `default_colleague_id` | UUID? | С кем |
| `pending_plan` | String? | Как у клиента |

**GroupMember — состав группы:** `group_id`, `client_id`, `from_date`, `to_date?`. Состав на дату подставляется в новую тренировку группы как ожидаемые участники.

**Training — тренировка или дежурство**

| Поле | Тип | Описание |
| --- | --- | --- |
| `type_id`, `location_id` | UUID | Тип и место |
| `start` | LocalDateTime | Начало в часовом поясе клуба |
| `duration_min` | Int | Длительность, от 5 до 600 |
| `series_id` | UUID? | Из какой серии |
| `series_detached` | Boolean | Изменена отдельно от серии (не перезаписывается при правке серии) |
| `group_id` | UUID? | Для групповых |
| `status` | `PLANNED` / `DONE` / `CANCELLED` | Статус самой тренировки (раздел 4.1) |
| `plan`, `fact` | String? | Дневник; у групп общие для всех |
| `owner` | `SELF` / `COLLEAGUE` | На ком числится (для негрупповых всегда `SELF`) |
| `owner_colleague_id` | UUID? | — |
| `conducted_by` | `SELF` / `SELF_AND_COLLEAGUE` / `COLLEAGUE` | Кто провёл |
| `colleague_id` | UUID? | С кем или кто заменил |
| `split_half` | Boolean | Сплит с одним клиентом засчитать как пол-сплита (раздел 4.7) |
| `cancel_reason` | String? | Причина отмены всей тренировки |
| `over_restriction` | Boolean | Поставлена поверх запрета (пересчитывается при каждом изменении тренировки и запретов, 4.5; у дежурства всегда `false`) |

Ещё у тренировки: `plan_carried_from_id` и `plan_carried_text` — откуда и какой текст плана перенесён (для отката, раздел 4.3); `done_at` — когда отмечена проведённой.

**Participation — участие клиента** (у ПТ и СПТ — одно, у сплита — до двух, у группы — сколько угодно, у дежурства — ни одного)

| Поле | Тип | Описание |
| --- | --- | --- |
| `training_id`, `client_id` | UUID | Связь; пара уникальна |
| `status` | `EXPECTED` / `ATTENDED` / `CANCELLED` / `CANCELLED_CHARGED` | Итог для этого клиента |
| `behavior` | String? | Поведение (только если включено у типа) |
| `cancel_reason` | String? | Причина отмены для этого клиента |
| `notified_at` | LocalDateTime? | Когда предупредили об отмене |
| `charge_overridden` | Boolean | Статус списания изменён вручную |

**Result — результат на дистанции**

| Поле | Тип | Описание |
| --- | --- | --- |
| `client_id`, `date` | UUID, Date | — |
| `style` | `FREESTYLE` / `BACKSTROKE` / `BREASTSTROKE` / `BUTTERFLY` / `MEDLEY` | Вольный стиль, на спине, брасс, баттерфляй, комплекс |
| `distance_m` | Int | 25, 50, 100, 200, 400, 800, 1500 |
| `pool_m` | Int | 25 или 50 |
| `time_cs` | Int | Время в сотых долях секунды (52,16 с = 5216) |
| `kind` | `TRAINING` / `COMPETITION` | Тренировка или соревнования |
| `event_name`, `note` | String? | Название старта, примечание |

**SptCase — стартовая тренировка и её закрытие:** `client_id`, `spt_training_id`, `spt_date`, `window_until` (та же дата следующего месяца), `purchase_date?`, `status` (`OPEN` / `CLOSED` / `NOT_CLOSED`).

**WaitEntry — запись листа ожидания** (4.16): `client_id`, `wants_series` и `wants_one_off` (Boolean, хотя бы одно: ждёт постоянное расписание и/или разовое посещение), `days` (дни недели; пусто — любой), `time_ranges` (список промежутков начала «с–до»; пусто — любое), `location_id?` (пусто — любое), `type_id`, `until?` (срок для разового), `note`, `created_at`, `contacted_at?`, `match_one_off`, `match_slot?` и `match_date?` (какое время освободилось: `match_slot` — время начала, `match_date` — дата разового или дата, с которой освободилось постоянное; день недели — по этой дате), `status` (`WAITING` / `BOOKED` / `CLOSED`), `closed_at?`. В кабинет не передаётся.

**ClientRelation — родственная связь** (4.17): одна запись на пару клиентов, обе карточки читают её каждая со своей стороны. В кабинет не передаётся.

| Поле | Тип | Описание |
| --- | --- | --- |
| `client_a_id`, `client_b_id` | UUID | Пара клиентов; пара уникальна, клиента нельзя связать с самим собой |
| `kind` | PARENT / GRANDPARENT / AUNT\_UNCLE / SIBLING / COUSIN / SPOUSE / OTHER | Первые три направленные: a — родитель, бабушка или дедушка, дядя или тётя для b. Остальные взаимные |
| `label_a`, `label_b` | String? | Только OTHER: кем a приходится b и кем b приходится a («крёстная» / «крестник», «отчим» / «пасынок») |
| `created_at` | DateTime | — |
