# 3.6. Деньги

Раздел [3. Модель данных](3.md) · [оглавление ТЗ](README.md)

**Colleague — коллега:** `name`, `linked_coach_id?` (если коллега тоже в приложении на том же сервере), `archived`. **ColleagueSchemeVersion:** `colleague_id`, `valid_from`, `kind` (как у PaySchemeVersion) — нужен только для доли налога владельца группы.

**MonthRecord — данные месяца:** `month` (ГГГГ-ММ), `plan_amount?`, `advance_actual?` (фактически полученный аванс), `closed` (месяц сверен и закрыт; правки тренировок закрытого месяца спрашивают подтверждение).

**MonthAdjustment — доплата или удержание:** `month`, `amount` (может быть отрицательной), `comment`, `in_club_accrual` (входит ли в начисление клуба и облагается налогом; по умолчанию да).

**ArchivedMonth — исторические итоги из импорта** (только чтение): `month`, `earned`, `tax`, `received`, `plan`, `pt_count`, `split_count`, `group_children`, `duty_hours`. Нужны для годовой сводки за месяцы до начала работы в приложении. Импорт отменён 23.10.2026 ([раздел 9](9.md)): таблица остаётся пустой, год показывает месяцы с месяца перехода.
