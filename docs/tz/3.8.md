# 3.8. Служебные таблицы

Раздел [3. Модель данных](3.md) · [оглавление ТЗ](README.md)

| Таблица | Где | Поля |
| --- | --- | --- |
| Outbox — очередь изменений | Телефон | `entity`, `entity_id`, `version`, `queued_at`, `attempts` |
| SyncState | Телефон | `last_pulled_seq`, `last_sync_at`, `last_error` |
| Account | Сервер | `coach_id`, `email`, `password_hash` (Argon2id), `role`, `status` (`ACTIVE` / `SUSPENDED`), `club_id` |
| Session | Сервер | `token_hash`, `coach_id`, `device_name`, `created_at`, `last_seen_at`, `expires_at` |
| Invite | Сервер | `code_hash`, `created_by`, `expires_at`, `used_by?`, `used_at?` |
| ChangeLog | Сервер | `seq` (сквозной номер), `coach_id` или `club_id`, `entity`, `entity_id`, `version` |
| AppRelease | Сервер | `platform`, `version_code`, `version_name`, `url`, `sha256`, `notes`, `min_supported_code` |
