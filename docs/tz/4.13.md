# 4.13. Поиск свободных слотов

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

Входные данные: период, дни недели и промежутки начала (по умолчанию все дни и рамки дня; из «Найти время» — как в записи листа ожидания), место (или любое), нужная длительность D (по умолчанию 50 мин), рамки дня, учитывать ли запреты, считать ли дежурство занятым временем (по умолчанию нет — во время дежурства тренер уже в бассейне), максимальный перерыв Gmax (пусто = без ограничения), показывать ли дни без тренировок, шаг сетки (15 мин).

Алгоритм для каждого дня:

1. Занято = неотменённые тренировки тренера + дежурства (если включено) + запреты выбранного места (если включено). Группа, которую ведёт коллега без тренера («Проводим: коллега»), не занимает. Место «Все» — окна ищутся в каждом помещении отдельно, со своими запретами (запрет «на все места» — запрет в каждом), и показываются по помещениям: клиенту ДБ время ББ не нужно (шаг 4.3а, просьба Дмитрия 27.10.2026; в шаге 4.3 «любое» место считало время закрытым, только если запрещено во всех местах, — запрет одного бассейна не учитывался).
2. Окна = рамки дня минус занятое; границы окон выравниваются по шагу.
3. Опоры = тренировки и дежурства этого дня. Если задан Gmax, каждое окно обрезается до частей, где слот начинается не позже чем через Gmax после конца опоры или заканчивается не раньше чем за Gmax до начала опоры. День без опор показывается целиком, только если включено «показывать пустые дни».
4. Оставляются окна длиной не меньше D; в прошлом сегодняшнего дня — отбрасываются.

Окно — промежуток, где слот длительностью D можно поставить с любого начала по сетке: от первого подходящего начала (по шагу) до конца слота с последнего (опущенного до шага). Без Gmax и промежутков начала это всё окно целиком. С Gmax соседние куски могут перекрываться: «15:00–16:30, 16:15–21:45» — в 16:00 начать нельзя, ждать больше часа и до, и после (шаг 4.3).

Результат: «Пн 03.11: 13:00–15:00, 18:00–19:00» (даты по ТЗ 10.6). Нажатие на окно создаёт тренировку в его начале (место — выбранное в поиске); из «Найти время» листа ожидания — сразу с этим клиентом, его типом и видом записи, как «Записать» (4.16). Кнопка «Скопировать список» даёт текст для отправки клиенту — «Свободное время:» и строки по дням, без имён и чужих тренировок. Окно, которое подходит записи листа ожидания, помечено «ждёт: Петров К.»; в скопированный список эти пометки не попадают. Пометка ставится, если в окне есть начало из промежутков записи, с которого влезает длительность её типа, день — её, место — её (при поиске по любому месту — не под запретом её места), у разового — не позже срока.
