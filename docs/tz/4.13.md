# 4.13. Поиск свободных слотов

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

Входные данные: период, дни недели и промежутки начала (по умолчанию все дни и рамки дня; из «Найти время» — как в записи листа ожидания), место (или любое), нужная длительность D (по умолчанию 50 мин), рамки дня, учитывать ли запреты, считать ли дежурство занятым временем (по умолчанию нет — во время дежурства тренер уже в бассейне), максимальный перерыв Gmax (пусто = без ограничения), показывать ли дни без тренировок, шаг сетки (15 мин).

Алгоритм для каждого дня:

1. Занято = неотменённые тренировки тренера + дежурства (если включено) + запреты выбранного места (если включено).
2. Окна = рамки дня минус занятое; границы окон выравниваются по шагу.
3. Опоры = тренировки и дежурства этого дня. Если задан Gmax, каждое окно обрезается до частей, где слот начинается не позже чем через Gmax после конца опоры или заканчивается не раньше чем за Gmax до начала опоры. День без опор показывается целиком, только если включено «показывать пустые дни».
4. Оставляются окна длиной не меньше D; в прошлом сегодняшнего дня — отбрасываются.

Результат: «Пн 3 ноя: 13:00–15:00, 18:00–19:00». Нажатие на окно создаёт тренировку в его начале. Кнопка «Скопировать список» даёт текст для отправки клиенту — без имён и чужих тренировок. Окно, которое подходит записи листа ожидания, помечено «ждёт: Петров К.»; в скопированный список эти пометки не попадают.
