# 4.13. Поиск свободных слотов

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

Входные данные: период, дни недели и промежутки начала (по умолчанию все дни и рамки дня; из «Найти время» — как в записи листа ожидания), место (или любое), нужная длительность D (по умолчанию 50 мин), рамки дня, учитывать ли запреты, считать ли дежурство занятым временем (по умолчанию нет — во время дежурства тренер уже в бассейне), максимальный перерыв Gmax (пусто = без ограничения), показывать ли дни без тренировок, шаг сетки (30 мин — начала занятий только в :00 и :30, шаг 4.3б).

Алгоритм для каждого дня:

1. Занято = неотменённые тренировки тренера + дежурства (если включено) + запреты выбранного места (если включено). Группа, которую ведёт коллега без тренера («Проводим: коллега»), не занимает. Место «Все» — окна ищутся в каждом помещении отдельно, со своими запретами (запрет «на все места» — запрет в каждом), и показываются по помещениям: клиенту ДБ время ББ не нужно (шаг 4.3а, просьба Дмитрия 27.10.2026; в шаге 4.3 «любое» место считало время закрытым, только если запрещено во всех местах, — запрет одного бассейна не учитывался).
2. Окна = рамки дня минус занятое; границы окон выравниваются по шагу.
3. Опоры = тренировки и дежурства этого дня. Если задан Gmax, каждое окно обрезается до частей, где слот начинается не позже чем через Gmax после конца опоры или заканчивается не раньше чем за Gmax до начала опоры. День без опор показывается целиком, только если включено «показывать пустые дни».
4. Оставляются окна длиной не меньше D; в прошлом сегодняшнего дня — отбрасываются.

Окно — промежуток, где слот длительностью D можно поставить с любого начала по сетке: от первого подходящего начала (по шагу) до конца слота с последнего (опущенного до шага). Без Gmax и промежутков начала это всё окно целиком. С Gmax куски могут стыковаться: «15:00–16:30, 16:30–21:30».

Результат — время начала занятий, отдельно по каждому помещению (шаг 4.3б, просьба Дмитрия 27.10.2026): в каждом окне все начала по сетке 30 мин, с которых слот D влезает до конца окна. Тренировка в 9:00, рамки с 7:00, D = 50 — «7.00 7.30 8.00». Нажатие на время создаёт тренировку на него в этом помещении; из «Найти время» листа ожидания — сразу с этим клиентом, его типом и видом записи, как «Записать» (4.16). Кнопка «Скопировать список» даёт текст для отправки клиенту — без имён и чужих тренировок:

```
ББ:
Вторник (27.10.2026): 8.00 9.00 15.00 16.00
Среда (28.10.2026): 15.00 20.30

ДБ:
Вторник (27.10.2026): 7.00 7.30
```

Помещения — по порядку справочника, между ними пустая строка; при одном помещении без мест в справочнике — только строки дней. День в помещении, где есть время для записи листа ожидания, помечен «ждёт: Петров К.»; в скопированный список эти пометки не попадают. Пометка ставится, если в окне есть начало из промежутков записи, с которого влезает длительность её типа, день — её, место окна — её (или она ждёт любое), у разового — не позже срока.
