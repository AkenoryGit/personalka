# 4.15. Клиенты без записи

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

Цель — не потерять клиента, который ходит, но не записан дальше. Список не хранится, а считается заново при открытии и после любой правки расписания.

- **Попадает в список** активный клиент, у которого за последние N дней (`followup_days`, по умолчанию 14, включая сегодня) есть проведённая тренировка индивидуального формата (`PERSONAL`, `SPLIT`, `SPT`), и нет ни одной будущей тренировки со статусом «Запланировано», где он участник.
- **Группы не учитываются:** ребёнка из группы «записывает» расписание группы. Если клиент ходит и на ПТ, и в группу, считаются только ПТ.
- **Уходит из списка сам**, как только появилась будущая тренировка, или когда последнее посещение стало старше N дней. Вторых видно в фильтре «Без записи» списка клиентов (5.8) — там все активные без будущих тренировок, без ограничения по дате.
- **Отложить:** «Написал» сохраняет дату связи и скрывает клиента на 3 дня; если записи так и нет — он возвращается с пометкой «писали 18.10». «Пауза до…» скрывает до выбранной даты (отпуск, болезнь) с короткой причиной, видной только тренеру.
- **После СПТ** у клиента пометка «после СПТ 12.10», такие идут первыми (4.9).
- В кабинет родителя ничего из этого не попадает.
