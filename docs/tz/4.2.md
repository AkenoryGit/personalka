# 4.2. Отмена и списание

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

1. Тренер указывает причину и время предупреждения `notified_at` (по умолчанию — сейчас).
2. Запас = `start` − `notified_at`. Если запас **меньше** `cancel_notice_minutes` (или предупредили после начала) — `CANCELLED_CHARGED`; иначе `CANCELLED`. Ровно 60 минут при настройке 60 — без списания. Время сравнивается с точностью до минуты: «Сейчас», нажатое в 09:00:45, — это 09:00, как и видно в панели; `notified_at` хранится без секунд. Предупредили ровно в начале — со списанием.
3. Причины «По инициативе тренера» и «По инициативе клуба» всегда дают `CANCELLED`. Свой текст, совпадающий с одной из них (без учёта регистра и пробелов по краям), — тоже. Если список чипов станет настраиваемым (5.6), эти два чипа не переименовываются и не удаляются.
4. Автоматический результат можно переключить вручную. `charge_overridden = true`, только пока итог расходится с правилом: переключили обратно — снова `false`.

По форматам:

- **ПТ и СПТ:** участие получает статус отмены, тренировка — `CANCELLED`. СПТ бесплатна для клиента, поэтому всегда `CANCELLED` без списания.
- **Сплит:** отмена по каждому клиенту отдельно. Тренировка становится `CANCELLED`, только если отменили оба; оплата при одном клиенте — 4.7. «Всю тренировку» отменяет ещё не отменённых клиентов, каждого по правилу; отменённый раньше сохраняет свою причину и списание.
- **Группа:** либо отдельные дети (тренировка остаётся), либо вся группа: тогда тренировка `CANCELLED`, все участия `CANCELLED` без списания, причина общая; `notified_at` детям не пишется — списания нет. Если по одному отменили всех детей, группа тоже становится `CANCELLED`, но у каждого остаётся свой статус, в том числе со списанием.
- **Дежурство:** `CANCELLED` без причины; клиентов в нём нет.
- **Отмена после окончания** (клиент не пришёл и не предупредил) — то же правило: предупредили после начала, значит, со списанием.

Перенос времени — не отмена: статус и план не меняются.
