# 4.2. Отмена и списание

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

1. Тренер указывает причину и время предупреждения `notified_at` (по умолчанию — сейчас).
2. Запас = `start` − `notified_at`. Если запас **меньше** `cancel_notice_minutes` (или предупредили после начала) — `CANCELLED_CHARGED`; иначе `CANCELLED`. Ровно 60 минут при настройке 60 — без списания. Время сравнивается с точностью до минуты: «Сейчас», нажатое в 09:00:45, — это 09:00, как и видно в панели; `notified_at` хранится без секунд. Предупредили ровно в начале — со списанием.
3. Причины «По инициативе тренера» и «По инициативе клуба» всегда дают `CANCELLED`. Свой текст, совпадающий с одной из них (без учёта регистра и пробелов по краям), — тоже. Если список чипов станет настраиваемым (5.6), эти два чипа не переименовываются и не удаляются.
4. Автоматический результат можно переключить вручную. `charge_overridden = true`, только пока итог расходится с правилом: переключили обратно — снова `false`.

По форматам:

- **ПТ и СПТ:** участие получает статус отмены, тренировка — `CANCELLED`. СПТ бесплатна для клиента, поэтому всегда `CANCELLED` без списания.
- **Сплит:** отмена по каждому клиенту отдельно. Тренировка становится `CANCELLED`, только если отменили оба; оплата при одном клиенте — 4.7. «Всю тренировку» отменяет ещё не отменённых клиентов, каждого по правилу; отменённый раньше сохраняет свою причину и списание.
- **Группа и мини-группа:** либо отдельные дети (тренировка остаётся), либо вся группа: тогда тренировка `CANCELLED`, все участия `CANCELLED` без списания, причина общая; `notified_at` детям не пишется — списания нет. **Отмена отдельного ребёнка — тоже без списания, при любом запасе и даже после начала** (решение Дмитрия 01.11.2026, шаг 5.3у: на группах ребёнок либо пришёл и списан, либо отменён без списания). В большой группе переключателя «Со списанием» нет совсем — исключительный случай отмечается «пришёл»; в мини-группе переключатель остаётся для исключений, по умолчанию выключен. Мини-группа — тип вида «Группа», чьё имя начинается с «Мини» (3.3, как в надёжности). Если по одному отменили всех детей, группа тоже становится `CANCELLED`, у каждого остаётся свой статус (со списанием — только включённое вручную в мини-группе).
- **Дежурство:** `CANCELLED` без причины; клиентов в нём нет.
- **Отмена после окончания** (клиент не пришёл и не предупредил) — то же правило: предупредили после начала, значит, со списанием.

Перенос времени — не отмена: статус и план не меняются.

## 4.2а. Не будет на период

Шаг 5.3у, просьба Дмитрия 01.11.2026: «нас не будет с 01.06 по 31.08» — отпуск, лето, сборы.

1. **Где:** меню «…» карточки клиента → «Не будет на период…» (у активного клиента с тренировками) и ссылка «Не будет несколько дней — отменить на период» внизу панели отмены, когда отменяют одного клиента (у ПТ и СПТ — всегда, в сплите и группе — выбран один). Обычная отмена выбора не получает: «Отменить» по-прежнему отменяет одну тренировку.
2. **Окно:** «С» (по умолчанию сегодня, из панели отмены — день тренировки), «По» (+13 дней), причина — те же чипы, по умолчанию «Отъезд», свой текст с подсказкой «Без диагнозов…». Итог: «Отменится 6 тренировок · вт 03.11 – чт 26.11»; если какие-то начинаются раньше порога — «Со списанием: N». Кнопка «Отменить 6 тренировок».
3. **Что отменяется:** тренировки клиента с днём начала в периоде, ещё не начавшиеся, запланированные, где он не отменён; дежурства — нет. Ошибки: «По» раньше «С», «С» в прошлом (прошедшие отменяются в карточке), период больше года.
4. **Как:** каждая — как отмена этого клиента из её карточки, причина одна, «предупредили» — сейчас, списание по 4.2 для каждой (у групп — без). ПТ и СПТ отменяются целиком, в сплите и группе — только он.
5. **Дальше горизонта:** перед подсчётом серии продлеваются до «По» (4.4) — иначе летние тренировки появились бы позже уже запланированными. Обычное продление их не дублирует.
6. **План:** отменённая целиком отдаёт план первой тренировке после периода; у той есть свой — дописывается с новой строки (вопрос 4.3 на каждую не задаётся); следующей нет — в отложенный план.
7. После записи — сообщение «Отменено 6 тренировок: 03.11–26.11» с «Отменить», которое возвращает все отмены и перенос плана. Освободившееся время попадает в лист ожидания (4.16).
