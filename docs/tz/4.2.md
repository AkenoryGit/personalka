# 4.2. Отмена и списание

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

1. Тренер указывает причину и время предупреждения `notified_at` (по умолчанию — сейчас).
2. Запас = `start` − `notified_at`. Если запас **меньше** `cancel_notice_minutes` (или предупредили после начала) — `CANCELLED_CHARGED`; иначе `CANCELLED`. Ровно 60 минут при настройке 60 — без списания.
3. Причины «По инициативе тренера» и «По инициативе клуба» всегда дают `CANCELLED`.
4. Автоматический результат можно переключить вручную (`charge_overridden = true`).

По форматам:

- **ПТ и СПТ:** участие получает статус отмены, тренировка — `CANCELLED`. СПТ бесплатна для клиента, поэтому всегда `CANCELLED` без списания.
- **Сплит:** отмена по каждому клиенту отдельно. Тренировка становится `CANCELLED`, только если отменили оба; оплата при одном клиенте — 4.7.
- **Группа:** либо отдельные дети (тренировка остаётся), либо вся группа: тогда тренировка `CANCELLED`, все участия `CANCELLED` без списания, причина общая.

Перенос времени — не отмена: статус и план не меняются.
