# 4.5. Запреты, дежурства, наложения

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

- При создании, переносе или смене места проверяются запреты (личные и клуба) **того же места**, пересекающиеся с интервалом \[начало, конец). Если есть — окно: «Малый бассейн 17:00–18:30: групповая тренировка. Поставить всё равно?» \[Отмена\] \[Поставить\]. При согласии `over_restriction = true`.
- При изменении самих запретов `over_restriction` пересчитывается для будущих тренировок без окон.
- Пересечение с дежурством и с другими своими тренировками разрешено без окна. На тренировке поверх дежурства — нейтральный значок; по нажатию: «Накладка с дежурством 15:00–19:00».
- Дежурства оплачиваются целиком даже если поверх них стоят тренировки.
