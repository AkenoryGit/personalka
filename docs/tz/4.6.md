# 4.6. Счётчик ПТ и ступень месяца

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

- **Месяц** — календарный, по дате начала тренировки в часовом поясе клуба.
- **Оплаченный клиент** — участие со статусом `ATTENDED` или `CANCELLED_CHARGED`.
- **Счётчик N** = число тренировок месяца, тип которых входит в `pt_type_ids` версии ступеней этого месяца, с хотя бы одним оплаченным клиентом. Сплит с двумя или одним клиентом = 1. ПТ в любом месте (ББ, ДБ, зал) считается. По умолчанию в списке ПТ, сплит, грудничковое, гидрореабилитация и кинезио; СПТ, группы и дежурства не считаются.
- **Ступень** берётся из версии ступеней, действующей 1-го числа месяца: 1, если N < 101; 2, если N < 151; иначе 3. Выключенная схема — всегда 1.
- **Итоговая ступень применяется ко всем** тренировкам месяца с `tier_dependent = true`, а не только к тем, что сверх порога.
- **Внутри месяца** показываются текущая ступень (по проведённым) и прогнозная (проведённые + `PLANNED` с `counts_toward_pt` до конца месяца). Заработок считается по текущей ступени, прогноз — по прогнозной.
- **Версии ступеней ещё нет** (она появляется с первым открытием «Зарплаты», 3.3) — ступень 1, а счётчик считается по отметкам «Считать как ПТ» типов. Отменённая тренировка с клиентом «со списанием» в счётчик идёт: клиент оплачен (пример 5). В прогнозе запланированная тренировка с ожидаемым клиентом считается состоявшейся. Решение шага 3.2 (25.10.2026).
