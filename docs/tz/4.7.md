# 4.7. Оплата одной тренировки

Раздел [4. Бизнес-правила и расчёты](4.md) · [оглавление ТЗ](README.md)

Ставка `rate(тип, место, дата, ступень)` берётся из RateVersion (3.3); для типов без ступеней — `amount_t1`. p — число оплаченных клиентов.

| Формат | Оплата |
| --- | --- |
| `PERSONAL` | p = 1 → ставка; p = 0 → 0 |
| `SPT` | Клиент пришёл → базовая ставка (200 ₽); доплата за закрытие — 4.9 |
| `SPLIT` | p = 2 → ставка сплита; p = 1 → ставка типа `split_fallback_type_id` (ПТ) в том же месте, а при `split_half` — половина ставки сплита; p = 0 → 0 |
| `GROUP` | p × ставка за клиента; дальше деление по 4.8 |
| `DUTY` | Длительность в минутах / 60 × ставка за час; отменённое — 0 |
| `OTHER` | По `pay_unit` типа |

- Округление до копеек по каждой тренировке, половина копейки — вверх.
- Сплит с одним клиентом остаётся в календаре сплитом, но с пометкой «как ПТ» или «пол-сплита». Если второй клиент — `CANCELLED_CHARGED`, p = 2 и оплачивается сплит (по умолчанию, см. открытые вопросы).
- Нет ставки → 0 и пункт в «Нужно сделать».
- Уточнения шага 3.2 (25.10.2026): у ставки нет суммы нужной ступени — берётся сумма ступени ниже (у ДБ нет ступени 3 — по ступени 2). СПТ оплачивается и при отмене со списанием (клиент оплачен, 4.6). Дежурство и `OTHER` без клиентов оплачиваются, когда проведены (`DONE`); в прогнозе — все неотменённые. Сплит с одним клиентом, у которого нет ставки ПТ в этом месте, — «нет ставки». Расчёт — `PayRules` в `shared/domain/money`.
