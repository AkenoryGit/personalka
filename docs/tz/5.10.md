# 5.10. Группы

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

Список постоянных групп: название, дни и время, место, число детей, на ком числится. Карточка группы: состав (добавить с даты, исключить с даты), расписание (серия), владелец и кто обычно ведёт, история тренировок с числом пришедших, средняя посещаемость. Ребёнка можно добавить прямо из отметки посещаемости («Добавить в состав»).
