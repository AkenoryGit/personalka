# 5.11. Результаты

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

Ввод: дата, стиль (чипы), дистанция (чипы), бассейн 25/50, время, тренировка или соревнования (название старта). Время вводится цифрами подряд с автоформатом: «5216» → 52,16; «10317» → 1:03,17. Новый личный рекорд отмечается надписью «Личный рекорд, − 7,00». Из карточки тренировки можно добавить результат с уже подставленными датой и клиентом.
