# 5.15. Статистика (отложена)

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

**Не входит в этапы 0–5.** Через 2–3 месяца работы в приложении решается, чего на самом деле не хватает, и делается только это. Ниже — список кандидатов, а не требования.

Период: месяц / квартал / год / свой. Показатели:

- тренировки по типам и местам; часы работы; заработок за час работы (заработано / часы тренировок и дежурств);
- доля отмен и отмен со списанием, клиенты с наибольшим числом отмен;
- конверсия СПТ;
- средняя посещаемость групп;
- тренировки поверх запрета за период;
- загрузка по дням недели и часам (тепловая карта).
