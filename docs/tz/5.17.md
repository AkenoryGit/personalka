# 5.17. Клуб (только администратор) — раздел отменён

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

- **Тренеры:** список со статусом, датой последней синхронизации и числом включённых кабинетов; «Приостановить», «Возобновить». Данные тренеров администратор не видит.
- **Приглашения:** «Создать код» (8 символов, действует 7 дней, одноразовый), список активных и использованных кодов, отзыв кода.
- **Общие данные клуба:** места, запреты клуба, сетка ставок, ступени.
- **Шаблон клуба:** выгрузка общих данных в файл для тренеров в режиме «Только телефон».
- **Сервер:** занятое место, последняя резервная копия и проверка восстановления, версия сервера.
- *Шаг 5.2 (26.10.2026):* «Тренеры» сделаны — «Ещё → Клуб» виден только администратору. Строка тренера: имя («· вы» у своей), почта, «Обмен сегодня» / «Обмен чт 22.10» / «Обмена не было», «Почта не подтверждена» или «Доступ приостановлен», «· 2 кабинета» (действующие ссылки). Нажатие — «Приостановить» / «Возобновить» с пояснением; администратора приостановить нельзя. Сервер отдаёт только аккаунты: данных тренеров администратор не видит. **«Приглашения» не делаются** — коды приглашения отменены 24.10.2026 (1.5, 7.3), регистрация открытая. Общие данные клуба, шаблон и «Сервер» — шаг 5.3 и дальше.
- *Решение 27.10.2026 (шаги 5.2б, 5.2в):* «Тренеры» переезжают из приложения в админку на сайте сервера `/admin` — вход только администратора: почта из `TRENER_ADMIN_EMAIL`, пароль и код из письма. Там же — возможности каждого тренера с датой «до», «Новым тренерам по умолчанию» и журнал. Остальное в «Клубе» (общие данные, шаблон, сервер — 5.3) остаётся в приложении у администратора.
- *Шаг 5.2б (27.10.2026):* в админке — список тренеров той же строкой, что в приложении (`ClubFormat`), «Приостановить» / «Возобновить» кнопкой (у администратора кнопки нет), журнал: «27.10 09:14 · Лена · приостановлен», «Вход в админку · Дмитрий · IP». «Ещё → Клуб → Тренеры» в приложении пока остаётся — уберётся на шаге 5.2в.
- *Шаг 5.2в (27.10.2026):* «Ещё → Клуб» из приложения убран вместе с экраном «Тренеры»; в админке — страница тренера с возможностями и датами «до», «Новым тренерам по умолчанию». Раздел «Клуб» в приложении появится снова на шаге 5.3 — с общими данными клуба, без тренеров.
- *Решение Дмитрия 28.10.2026 (шаг 5.3).* **Раздела «Клуб» в приложении нет.** Общих мест, запретов клуба, сетки ставок и ступеней клуба нет: каждый тренер заводит места, запреты и ставки сам; поэтому не нужен и «Шаблон клуба». Всё администрирование — в админке на сайте (`/admin`): тренеры, возможности, журнал и **строка «Сервер»** над списком тренеров — «Сервер 0.1.N · диск 7,4 из 19,6 ГБ (38 %) · копия базы сегодня 03:30». Копия берётся из файла `backup-status`, который пишет ночная копия (7.5). Строка красным, если последняя копия с ошибкой («копия базы не сделана 28.10 03:31 — шифрование»), её нет больше 36 часов, копий ещё не было или диск занят на 85 % и больше. Сетка ставок клуба (3.3) становится примером ставок — шаг 5.3а.
