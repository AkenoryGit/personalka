# 5.18. Первый запуск

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

1. Приветствие и выбор: «Начать на телефоне» / «Войти» (есть учётная запись на сервере, второе устройство) / «Восстановить из копии» / «У меня есть код приглашения» (с этапа 5). Кнопка появляется, когда её действие уже работает (10.7): «Войти» — с сервером (этап 2), «Восстановить из копии» — с копией (шаг 1.15); на шаге 1.6 — только «Начать на телефоне».
2. ФИО: фамилия, имя, отчество (отчество необязательно). Имя и фамилию родители увидят в кабинете, полное ФИО подставится в согласие как оператор данных; поменять — в «Профиле».
3. Места и типы — предложены по умолчанию (3.3) и отмечены, лишнее снимается, «+ Место» и «+ Новый тип» (тот же конструктор, что в настройках) — прямо здесь; остальное — потом в настройках. Снятые места и типы не создаются вовсе. «Готово» доступно, когда отмечено хотя бы одно место и один тип. «Загрузить шаблон клуба» — когда появятся шаблоны клуба на сервере (этап 2).
4. Календарь с подсказкой «Удерживайте пустое место, чтобы добавить тренировку» (подсказка — вместе с календарём, шаг 1.9).

До «Готово» в базу ничего не пишется: тренер, его настройки, места и типы записываются одной транзакцией, поэтому прерванный первый запуск начинается заново без следов. Введённое до «Готово» переживает сложение Fold, смену темы и выгрузку приложения из памяти.

Весь первый запуск — меньше минуты, про зарплату в нём ничего не спрашивается. При первом открытии «Зарплаты» — три шага: категория → схема выплат → ставки из сетки клуба по категории с проверкой. Папка резервной копии тоже не спрашивается сразу: пока она не выбрана, на главной в «Нужно сделать» висит пункт «Выберите папку для копии».
