# 5.19. Уведомления

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

Все уведомления локальные (формирует телефон). Основное — одна **вечерняя сводка**: в выбранное время одно уведомление со всеми делами дня: «3 без дневника · 2 клиента без записи · группа не отмечена». Если дел нет, уведомление не приходит. Нажатие открывает главную с блоком «Нужно сделать»; кнопка «Дневник» в уведомлении сразу открывает первую тренировку без дневника. Мгновенные напоминания выключены по умолчанию и включаются в «Настройки → Дневник и напоминания → Дополнительно».

| Уведомление | Когда | По умолчанию |
| --- | --- | --- |
| Вечерняя сводка | В 21:00 (время настраивается). Внутри — пункты «Нужно сделать» (5.2): тренировки без дневника, группы без отметки, новые клиенты без записи (4.15), освободившееся время для листа ожидания (4.16), СПТ с окном меньше 3 дней, нет резервной копии 7 дней | Вкл. |
| Аванс | 25-го в 19:00: «Введите сумму аванса» | Вкл. |
| Дневник сразу | Через 15 мин после конца тренировки без дневника | Выкл. |
| Группа сразу | Через 15 мин после конца группы без отметки | Выкл. |
| План на день | В 07:00: «Сегодня 9 тренировок, первая в 08:00» | Выкл. |

**Шаг 2.5 (24.10.2026).**

- **Сводка — это «Нужно сделать» целиком:** те же пункты и то же число, что на «Главной» (5.2), в том же порядке, включая пункт про копию. Заголовок — «Нужно сделать: 3», текст — «Группа не отмечена · 3 без дневника · 2 клиента без записи». Пунктов нет — уведомления нет. Повторная проверка в тот же вечер сводку не повторяет.
- **Кнопка «Дневник»** есть, только когда есть тренировки без дневника; открывает первую из них на момент нажатия (не на момент сводки). Нажатие на саму сводку — «Главная».
- **«Дневник сразу»** приходит и о группе, если детей уже отметили, а дневника нет; нажатие — дневник этой тренировки. **«Группа сразу»** — карточка группы прямо на «Главной». Заголовок — имя клиента или группа, текст — «16:00–16:50 · заполните дневник» / «… · отметьте, кто пришёл». Если дневник уже заполнен или группу отметили, напоминание не приходит.
- **«План на день»** — настройка этого телефона (в `coach_settings` поля для неё нет, новая версия базы ради неё не делалась). Тренировок нет — не приходит. **«Аванс»** — с зарплатой на этапе 3.
- **Время.** Будильник неточный: уведомление может прийти на несколько минут позже (точный требует отдельного разрешения тренера). После перезагрузки, обновления приложения и смены времени будильник ставится заново. Проверка берёт всё, что наступило с прошлой, но не дальше 12 часов назад: телефон выключили на ночь — утром придёт пропущенная сводка, напоминания прошлых дней — нет.
- **Разрешение Android 13+** спрашивается один раз, после первого запуска. Уведомления выключены — в «Дневник и напоминания» сверху строка «Уведомления «Персоналки» выключены в настройках телефона» и «Включить».
- Проверка по будильнику заодно закрывает прошедшие тренировки (4.1) и продлевает серии (5.5) — как при открытии приложения.
- Два канала в настройках телефона: «Вечерняя сводка» и «Напоминания» — их можно выключить по отдельности.
