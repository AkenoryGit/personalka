# 5.3. Календарь

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

**Виды.** День (по умолчанию на сложенном), Несколько дней (3, 5 или 7 — по умолчанию на разложенном), Месяц (сетка дней с числом тренировок без отменённых и цветными точками — до четырёх самых частых типов дня; под сеткой — список выбранного дня), Список (по дням). Последний вид запоминается отдельно для сложенного и разложенного состояния.

**Шапка:** месяц и год (нажатие — мини-календарь), «Сегодня», переключатель вида, фильтр мест (все / ББ / ДБ / Зал) — фильтр скрывает тренировки и запреты других мест. В виде «День» под шапкой — строка недели пн–вс: нажатие открывает день, сегодняшнее число — в оранжевом кружке.

**Сетка.** Колонка времени 48 dp, линии каждый час, пунктир на полчаса. Сетка показывает часы работы из настроек (по умолчанию 07:00–23:00 — часы клуба), ночь не показывается. Если в видимых днях есть тренировка раньше или позже, сетка этих дней расширяется до её полного часа: тренировка в 06:30 — сетка с 06:00. Тренировку вне часов работы создают кнопкой «+», время в форме любое. При открытии — прокрутка к «сейчас минус 1 час», но не дальше конца часов работы: в 15:40 на сложенном Fold виден 11:00–23:00. Линия текущего времени — фирменная оранжевая с точкой. Прошедшее время слегка приглушено (только фон сетки, блоки сохраняют цвета). Щипок двумя пальцами меняет высоту часа от 40 до 160 dp (по умолчанию 64 dp), масштаб запоминается — на этом телефоне, а не в настройках тренера: на другом экране свой (шаг 1.9). Щипок держит под пальцами то же время. Свайп влево-вправо — следующие и предыдущие дни. В виде «День» часы сетки берутся по дню, на котором листание остановилось.

**Слои снизу вверх:** фон дня → дежурства (сплошной фон цвета типа «Дежурство», непрозрачность 20%) → запреты (штриховка 45°, линии 1,5 dp через 8 dp, нейтральный цвет 35%) → линии сетки → тренировки → линия текущего времени → перетаскиваемый блок. У левого края колонки дня — полоски шириной 4 dp для каждой зоны (дежурство — сплошная, запрет — штрихованная цветом рамок полей, чтобы полоска читалась не хуже 3 : 1); тренировки начинаются в 8 dp от края и полоски не перекрывают. Нажатие на полоску или видимую часть зоны показывает её: «ДБ 17:00–18:30 — групповая тренировка», с кнопками «Изменить» и «Пропустить этот день».

**Блок тренировки.** Фон — цвет типа со светлым тоном, слева полоса 3 dp насыщенного цвета типа, текст тёмным оттенком того же цвета (в тёмной теме наоборот: тёмный фон, светлый текст). Вокруг блока — зазор 1 dp цвета фона сетки, значки сидят в кружках 16 dp цвета фона. Содержимое по высоте блока:

| Высота | Содержимое |
| --- | --- |
| от 56 dp | Имя («Иванов И.», «Петров / Сидоров», «Сб 9:00 ББ (12)»), время, тип · место |
| 40–56 dp | Имя и «начало · место» («08:00 · ББ») |
| меньше 40 dp | Имя и начало одной строкой («Белова Е., 10:00»), лишнее — многоточием |

При часе 64 dp тренировка на 60 минут показывает три строки, на 45–50 минут — две, на 30 минут — одну. Место видно на всех блоках от 40 dp: по нему тренер различает бассейны. Макеты календаря — на холсте [«Персоналка — макеты»](https://claude.ai/artifact/6PXCx6ETyZfXgxgxyEvqzQ) (шаг 0.3).

Значки в правом верхнем углу. На блоке ниже 56 dp — один значок, самый важный по порядку: «₽» (отмена со списанием) → фиолетовый треугольник (поверх запрета) → точка (не заполнен дневник) → серые «слои» (поверх дежурства) → галочка (проведено). На блоке от 56 dp — до двух значков в том же порядке. Все значки с пояснениями — в карточке тренировки (5.4). Отменённые — серые и зачёркнутые, с нейтральным фоном и текстом без прозрачности, чтобы текст оставался не ниже 4,5 : 1; их показ можно выключить.

**Раскладка наложений:**

1. Тренировки дня сортируются по началу, при равенстве — более длинные первыми.
2. Пересекающиеся цепочкой объединяются в кластер.
3. В кластере каждая тренировка получает первую колонку, в которой предыдущая уже закончилась.
4. Ширина = ширина дня / число колонок кластера; блок растягивается вправо на свободные колонки.
5. Минимальная ширина 36 dp; если колонок больше 4, показываются 3 и метка «+N» со списком.

Уточнения шага 1.9: тренировка, которая кончается ровно в начале другой, с ней не пересекается. Сколько колонок помещается, считается от ширины дня без отступов по 8 dp (не уже 36 dp, от двух до четырёх): в узкой колонке «3 дня» на сложенном — две, то есть одна и «+N». Метка «+N» стоит в последней колонке кластера; скрытые в разное время получают каждая свою метку. Нажатие на метку — список «Ещё 2 тренировки» со временем и местом, нажатие в списке — как на блок.

**Имя блока** (шаг 1.9): один клиент — «Иванов И.»; двое и больше — фамилии через « / » в порядке, в котором клиентов добавили; группа — название и в скобках число детей, которых ждут (отменённые не считаются, у отменённой тренировки — все записанные); без клиентов — название типа. Строки по высоте считаются от полной длительности: 60 минут при часе 64 dp — 64 dp, три строки. Дежурства блоками не рисуются — это заливка под тренировками (шаг 1.10).

**Жесты:**

| Жест | Результат |
| --- | --- |
| Нажатие на тренировку | Карточка тренировки (5.4) |
| Длительное нажатие (400 мс) на пустое место | Вибрация → быстрое создание с временем под пальцем (округление вниз до шага) |
| Длительное нажатие на тренировку и движение | Перетаскивание: блок приподнимается, на старом месте призрак, над пальцем подсказка «Вт 22.10 · 17:15–18:15»; привязка к шагу; перенос между колонками дней; у края экрана — автопрокрутка; в виде «День» задержка 600 мс у бокового края листает день |
| Длительное нажатие на тренировку без движения (сдвиг меньше 8 dp) | Меню: «Новая тренировка на это время», «Отменить», «Копировать» |
| Щипок | Масштаб по вертикали |

После перетаскивания: для серии — вопрос «Только эту / Эту и следующие», затем проверка запретов (4.5), затем сообщение «Перенесено на вт 22.10, 17:15» с кнопкой «Отменить» (5 секунд). «Копировать» запоминает тип, клиентов, место и длительность; при следующем создании первой строкой предлагается «Вставить скопированную».

**Скорость:** прокрутка и перетаскивание без пропуска кадров (60 кадров в секунду) при 200 тренировках на экране. Сетка рисуется на Canvas, а не отдельными элементами на каждый блок.
