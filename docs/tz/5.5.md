# 5.5. Создание и изменение

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

Одна форма для быстрого создания и редактирования. Сверху переключатель **Тренировка / Дежурство / Запрет**.

| Поле | Поведение |
| --- | --- |
| Тип | Чипы типов, последний использованный первым |
| Клиент(ы) или группа | Поиск по мере ввода, над полем — недавние клиенты. Нет в списке — «Новый клиент» с проверкой похожих имён (5.8). ПТ и СПТ — ровно один, сплит — один или два (вторым первыми предлагаются родственники первого, 4.17), группа — группа или разовый список |
| Место | Чипы; по умолчанию место группы или последнее для этого типа |
| Дата и время | Из места нажатия или ближайший свободный час |
| Длительность | Чипы 30 / 45 / 50 / 60 / 90 + своя; по умолчанию — из типа (50) |
| Повтор | «Не повторять» / «Каждую неделю»: дни недели (по умолчанию день даты), «бессрочно» или «до даты» |
| Проводим / числится на | Только для групп и при включённом совместном ведении |
| План | Необязательно |

Для **Дежурства**: место, время, повтор. Для **Запрета**: место, время, причина, повтор, период, «Для всего клуба» (только администратор).

Проверки при сохранении: обязательные поля заполнены; длительность 5–600 минут; конец не позже 24:00; запреты (4.5). Ошибка показывается под полем. Изменение тренировки серии спрашивает «Только эту / Эту и следующие».
