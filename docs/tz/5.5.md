# 5.5. Создание и изменение

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

Одна форма для быстрого создания и редактирования. Сверху переключатель **Тренировка / Дежурство / Запрет**.

| Поле | Поведение |
| --- | --- |
| Тип | Чипы типов, последний использованный первым |
| Клиент(ы) или группа | Поиск по мере ввода, над полем — недавние клиенты. Нет в списке — «Новый клиент» с проверкой похожих имён (5.8). ПТ и СПТ — ровно один, сплит — один или два (вторым первыми предлагаются родственники первого, 4.17), группа — группа или разовый список |
| Место | Чипы; по умолчанию место группы или последнее для этого типа |
| Дата и время | Из места нажатия или ближайший свободный час |
| Длительность | Чипы 30 / 45 / 50 / 60 / 90 + своя; по умолчанию — из типа (50) |
| Повтор | «Не повторять» / «Каждую неделю»: дни недели (по умолчанию день даты), «бессрочно» или «до даты» |
| Проводим / числится на | Только для групп и при включённом совместном ведении |
| План | Необязательно |

Для **Дежурства**: место, время, повтор. Для **Запрета**: место, время, причина, повтор, период, «Для всего клуба» (только администратор).

Проверки при сохранении: обязательные поля заполнены; длительность 5–600 минут; конец не позже 24:00; запреты (4.5). Ошибка показывается под полем. Изменение тренировки серии спрашивает «Только эту / Эту и следующие».

*Уточнения 23.10.2026 (шаг 1.13):*

- **Форма — поверх всего приложения**, её открывают «+» на «Главной» и в «Календаре», удержание на пустом месте, «Новая тренировка на это время» в меню блока; до карточки тренировки (5.4, шаг 1.14) нажатие на тренировку открывает её форму изменения. Нажатие мимо панели форму не закрывает — только «✕» и «Назад».
- **Переключатель «Тренировка / Дежурство / Запрет»** появляется вместе с формами дежурства и запрета (шаг 1.13а); до этого форма — только тренировки.
- **Тип:** пять чипов, остальные — под «Ещё N»; последний использованный — тип последней созданной тренировки. Сменили тип — длительность из нового типа (если тренер не менял её сам), место — последнее для этого типа, лишние клиенты убираются.
- **Клиенты:** над поиском — выбранные и три недавних (клиенты последних созданных тренировок). У сплита с двумя выбранными новый встаёт вторым. «Новый клиент «…»» — из строки поиска: фамилия, имя и, если есть, отчество; похожий (5.8) — окно «Похожий клиент уже есть» с «Да, выбрать» и «Нет, создать нового». У группового типа — чипы групп (сначала этого типа), без группы — «Или дети на раз».
- **Ближайший свободный час** («+»): первый целый час после «сейчас» в часы работы, где тренировка нужной длительности не задевает другие (дежурства не мешают); сегодня всё занято — завтра с начала работы.
- **Повтор у тренировки серии** в форме изменения виден строкой «Каждый вт и чт · бессрочно» и здесь не меняется: день и время всех следующих меняет «Эту и следующие» (4.4), дни и конец серии — «Изменить с даты…» и «Завершить» в карточке клиента (5.9). Разовая тренировка с «Каждую неделю» становится первой тренировкой новой серии.
- **Вопрос «Только эту / Эту и следующие»** не задаётся, когда «Эту и следующие» невозможно (тренировка или новая дата в прошлом), — меняется только эта. Тот же вопрос — при переносе тренировки серии в календаре (5.3), третья кнопка там — «Отмена».
- **План серии** — у первой тренировки. **«Проводим / числится на»** — с совместным ведением (этап 3); до него «числится» и «проводим» берутся из группы.
- **После сохранения** — сообщение «Создано: вт 20.10, 17:15», «Создано: каждый вт и чт, 17:15», «Перенесено на …», «Сохранено» или «Изменены эта и следующие» с «Отменить» (5.20): всё, что записало сохранение, возвращается как было.
- **Серии продлеваются** до горизонта при открытии приложения и при смене дня; фоновая задача раз в сутки — вместе с уведомлениями (2.5).

*Уточнения 23.10.2026 (шаг 1.13а):*

- **Переключатель «Тренировка / Дежурство / Запрет»** — только у новой записи, под заголовком панели. Время из места нажатия (или ближайший свободный час у «+») переходит в каждую форму; недописанное в одной форме не теряется при переходе в другую. Изменение открывает форму того, что меняют, без переключателя. Нет типа дежурства (его убрали в архив) — нет и «Дежурства» в переключателе (10.7).
- **Дежурство** — тренировка типа «Дежурство»: место (по умолчанию — последнее у дежурств), дата, время «с 11:00 — до 15:00» (новое — на длительность типа, 4 часа, но не дальше полуночи), повтор, как у тренировки. Сменили начало — конец «до» остаётся на месте. Ошибки — «Конец должен быть позже начала», «Не дольше 10 часов» (5–600 минут, как у тренировки). Серия, вопрос «Только эту / Эту и следующие» и «Отменить» — те же, что у тренировки; с запретами дежурство не сверяется (4.5). Сообщение — «Создано: вт 20.10, 11:00» / «Создано: каждый вт, 11:00».
- **Запрет** — макет «Запрет»: место, время «с — до» (новый — на час; «до 24:00» — конец дня), причина (необязательно; подсказка «Например, групповая тренировка»), повтор «Не повторять / Каждую неделю» с днями недели (по умолчанию день даты), у повторяющегося — «Период: с 01.09.2026 — до бессрочно», у разового — «Дата». Ошибки — «Выберите место», «Конец должен быть позже начала», «Выберите дни недели», «Не раньше начала периода». После записи флаг «поверх запрета» у тренировок, которые ещё не начались, пересчитывается без окон (4.5); пропущенные дни («Пропустить этот день») при изменении запрета остаются. Сообщения — «Запрет создан», «Запрет сохранён» с «Отменить».
- **«Удалить запрет»** — внизу формы изменения своего запрета; сообщение «Запрет удалён» с «Отменить». Без него убрать запрет, поставленный по ошибке, было бы негде.
- **«Для всего клуба»** — только администратору (этап 2), до него не показывается. Запреты клуба тренер не меняет: в окне зоны у них нет «Изменить», только «Пропустить этот день». Свои запреты пишутся с областью «тренер» (`scope = COACH`).
- **«Изменить» в окне зоны** (5.3) открывает форму дежурства или своего запрета; строка дежурства в «Месяце» и «Списке» открывает то же окно.
