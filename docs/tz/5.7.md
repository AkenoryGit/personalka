# 5.7. Дневник тренировки

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

Экран для записи после занятия. Поля — по настройкам типа:

- **План был:** показывается для справки, можно исправить.
- **Факт** — что делали.
- **Поведение** — у группы нет; у сплита — по полю на каждого ребёнка.
- **План на следующую** — с подписью даты («Вт 22.10, 10:00»); записывается в план следующей тренировки (4.3).

У полей — голосовой ввод системной клавиатуры и подсказка «Без диагнозов и сведений о здоровье» (10.3). У группы под полем факта подсказка: «Видят родители всех детей — не пишите имён». Черновик сохраняется при каждом вводе. Кнопка «Следующая без дневника» позволяет заполнить записи за день подряд.

**Когда дневника нет** (шаг 1.10, `DiaryRules.missing`): тренировка проведена, дневник включён в настройках (3.2), у типа ведётся факт (3.3), а факт пуст. План пишут до занятия, поведение — по желанию, поэтому заполненность считается по факту; у дежурства факта нет. По этому правилу — точка в календаре (5.3), пункт «Нужно сделать» (5.2), вечерняя сводка и «Следующая без дневника».

**Шаг 2.1 (23.10.2026).** Дневник — экран поверх приложения по макетам «Дневник ПТ», «Дневник сплита», «Дневник группы». Уточнения:

- **Откуда открывается:** «Дневник» в карточке (у идущей с начала минус 15 минут и у проведённой; у проведённой без факта — главная кнопка), в «Ближайшей» на «Главной» рядом с «Проведено» и пункт «Без дневника» в «Нужно сделать» — дневник самой ранней. Кнопки нет у отменённой, у дежурства, у типа без полей дневника и при выключенном дневнике (3.2).
- **Черновик** — каждая правка сразу пишется в саму тренировку (план, факт, поведение в участии); отдельной таблицы черновиков нет, «Сохранить» нет, под полями — «Черновик сохранён». Пустое поле — пусто в базе; одни пробелы — не факт.
- **«План был»** пустой не показывается (10.7); непустой — для справки, карандаш открывает правку.
- **«План на следующую»** показывает и правит план самой «следующей» (4.3) — с её датой в подписи. Следующей нет — подпись «План на следующую · в первую новую», текст пишется в `pending_plan` группы или каждого клиента. Сплит без серии ищет тренировку, где есть все его клиенты.
- **«Следующая без дневника»** — ближайшая по времени проведённая без факта после открытой, после последней — самая ранняя; список не ограничен днём, чтобы ни одна запись не терялась. Других нет — кнопки нет; справа в шапке — «ещё 2 без дневника».
- **Голосовой ввод:** микрофон в поле открывает системное распознавание речи по-русски и дописывает услышанное в конец поля; разрешения на микрофон приложению не нужно. На телефоне без распознавания микрофонов нет — остаётся голосовой ввод клавиатуры.
- **Поведение видно и в карточке:** «Поведение», у сплита — «Поведение · Ковалёв Т.».
