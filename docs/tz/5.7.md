# 5.7. Дневник тренировки

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

Экран для записи после занятия. Поля — по настройкам типа:

- **План был:** показывается для справки, можно исправить.
- **Факт** — что делали.
- **Поведение** — у группы нет; у сплита — по полю на каждого ребёнка.
- **План на следующую** — с подписью даты («Вт 22.10, 10:00»); записывается в план следующей тренировки (4.3).

У полей — голосовой ввод системной клавиатуры и подсказка «Без диагнозов и сведений о здоровье» (10.3). У группы под полем факта подсказка: «Видят родители всех детей — не пишите имён». Черновик сохраняется при каждом вводе. Кнопка «Следующая без дневника» позволяет заполнить записи за день подряд.
