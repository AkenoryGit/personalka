# 5.9. Карточка клиента

Раздел [5. Приложение тренера](5.md) · [оглавление ТЗ](README.md)

**Шапка:** имя, возраст, метка «Ребёнок»/«Взрослый», постоянное расписание, метка «Ждёт время: вт, чт · 07–12» (нажатие — запись листа ожидания), счётчики чипами: проведено · отменено · со списанием · в среднем в месяц. Кнопки: «+ Тренировка», «+ Результат», «Кабинет».

**Вкладки:**

| Вкладка | Содержимое |
| --- | --- |
| Тренировки | Вверху ближайшие (число из настроек, 4) с планом у ближайшей; ниже история от новых к старым: дата, время, тип · место, статус, раскрывается в план / факт / поведение или причину отмены. Фильтр: все / проведённые / отменённые |
| Результаты | Личные рекорды по дистанциям (отдельно 25 и 50 м бассейн), график времени по выбранной дистанции (соревнования — залитые точки, тренировки — пустые), список всех результатов |
| Инфо | Данные клиента и пол, родственники (см. ниже), контакт, ссылка на фото и видео, имя в 1С, внутренняя заметка (значок замка, подпись «Видна только вам»), СПТ и её статус с кнопкой «Купил блок со скидкой» |
| Расписание | Серии клиента: дни, время, тип · место, с какой даты; «Изменить с даты…», «Завершить», «+ Серия» |

**Кабинет** (режим «С сервером» и включённые кабинеты): выключатель для клиента; «Отправить ссылку» (системное «Поделиться» с готовым текстом: «Здравствуйте! Здесь расписание и итоги тренировок …: ссылка»); «Скопировать»; «Выпустить новую ссылку» (старая перестаёт работать); «Код доступа» (4 цифры, вкл/выкл); «Как видит родитель»; «Последний раз открывали: вчера, 21:14».

**Меню «…»:** Изменить, В лист ожидания…, Объединить с…, В архив, Удалить полностью (двойное подтверждение с вводом фамилии).

**Родственники** (вкладка «Инфо», правила — 4.17): строка — кем приходится, имя, возраст и расписание коротко («Сестра · Ковалёва Алиса · 12 лет · Вт, Чт 09:00 · Сплит ББ»); у клиента в архиве — пометка «в архиве». Нажатие открывает карточку родственника, «Назад» возвращает обратно; в меню строки — «Изменить связь», «Убрать связь». Под списком — «+ Родственник»; пусто — «Родственников нет» и та же кнопка.
