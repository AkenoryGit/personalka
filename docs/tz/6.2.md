# 6.2. Безопасность

Раздел [6. Кабинет родителей](6.md) · [оглавление ТЗ](README.md)

- Сервер собирает страницу только из данных клиента, найденного по токену. Нет ни одного адреса, который возвращал бы списки или чужие данные.
- **Никогда не попадают в кабинет:** внутренняя заметка, другие участники тренировки, название группы, расписание тренера, оплата, коллеги, имя в 1С, контактный телефон, служебные отметки (поверх запрета, ставки), лист ожидания, пол и родственные связи (4.17).
- Нет внешних скриптов, шрифтов и счётчиков. Заголовки: `Content-Security-Policy: default-src 'self'`, `X-Robots-Tag: noindex, nofollow`, `Referrer-Policy: no-referrer`, `Cache-Control: private, no-store`; `robots.txt` запрещает `/c/`.
- Ограничение: 30 запросов в минуту с одного IP к `/c/`.
- В журналах сервера токен замаскирован, имена не пишутся.
