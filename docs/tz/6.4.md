# 6.4. «Как видит родитель»

Раздел [6. Кабинет родителей](6.md) · [оглавление ТЗ](README.md)

Кнопка в карточке клиента сначала запускает синхронизацию, затем открывает тот же адрес во встроенном браузере с признаком предпросмотра (время «последний раз открывали» не меняется). Если часть изменений не ушла на сервер — плашка «Родитель пока не видит N последних изменений». Без интернета кнопка показывает «Нужен интернет».

**Шаг 2.13б (24.10.2026).** Кнопка — строка «Как видит родитель» со значком глаза в окне «Кабинет» (5.9, макет ClCabinet), у взрослого клиента — «Как видит клиент»; есть, когда ссылка выпущена, и без связи тоже. Нажатие: «Отправляем изменения…», обмен с сервером, затем кабинет открывается на месте окна — сверху «Как видит родитель» с крестиком и строкой «Тот же кабинет — время „Последний раз открывали“ не меняется», под ней, если после обмена часть правок так и не ушла, — плашка «Родитель пока не видит 3 последних изменения» (число со склонением). Крестик и «Назад» возвращают к окну «Кабинет». Без связи — сообщение «Нужен интернет», кабинет не открывается.

Признак предпросмотра — не параметр в адресе, а **короткий токен по сессии тренера**: `POST /api/v1/cabinets/{client}/preview` отдаёт случайный токен на 15 минут, страница `/p/<токен>` — тот же кабинет (`CabinetRules.page`), но без кода доступа и без экрана согласия, и сервер не пишет «последний раз открывали». Подделать признак посторонний не может: токен знает только телефон тренера, а ссылка родителя на `/p/` не открывается. **Согласия ещё нет** — кабинет показывается как после согласия без фото: без «Фото и видео» и без строки «Согласие на обработку данных дано…»; согласие из предпросмотра не записывается. «Отозвать согласие» в подвале видно, но не нажимается. Встроенный браузер на Android — `WebView` без JavaScript и доступа к файлам; страницы своего сервера открываются внутри, ссылка «Фото и видео» — в браузере телефона. iOS — на этапе 5.
