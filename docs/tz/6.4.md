# 6.4. «Как видит родитель»

Раздел [6. Кабинет родителей](6.md) · [оглавление ТЗ](README.md)

Кнопка в карточке клиента сначала запускает синхронизацию, затем открывает тот же адрес во встроенном браузере с признаком предпросмотра (время «последний раз открывали» не меняется). Если часть изменений не ушла на сервер — плашка «Родитель пока не видит N последних изменений». Без интернета кнопка показывает «Нужен интернет».
