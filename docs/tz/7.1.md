# 7.1. API

Раздел [7. Сервер и синхронизация](7.md) · [оглавление ТЗ](README.md)

REST + JSON, префикс `/api/v1`, авторизация — заголовок `Authorization: Bearer <токен сессии>`. Ошибка — `{"code": "wrong_code", "message": "Неверный код. Осталось 4 попытки"}`, текст на русском для показа пользователю.

| Метод и адрес | Назначение | Доступ |
| --- | --- | --- |
| `POST /auth/register` | Открытая регистрация: `email`, `password`, `display_name`, `coach_id` (необязательно — id тренера из телефона) → письмо с кодом | Публично, лимит |
| `POST /auth/confirm` | Подтверждение почты: `email`, `password`, `code`, `device_name` → токен сессии | Код из письма |
| `POST /auth/login` | Вход: `email`, `password`, `device_name` → токен; почта не подтверждена — новый код и 403 `email_not_confirmed` | Публично, 5 в минуту |
| `POST /auth/reset/request` | Код для нового пароля на почту (ответ одинаковый, есть аккаунт или нет) | Публично, лимит |
| `POST /auth/reset` | Новый пароль: `email`, `code`, `password`, `device_name` → токен; остальные устройства выходят | Код из письма |
| `POST /auth/logout` | Завершить сессию | Тренер |
| `GET /me` | Профиль, роль, статус, открытые возможности с датой «до» (`features`: `code`, `until`), список сессий | Тренер |
| `DELETE /me/sessions/{id}` | «Выйти на этом устройстве» | Тренер |
| `POST /sync/push` | Отправить изменения (до 500 за раз) | Тренер |
| `GET /sync/pull?since=&limit=` | Получить изменения после номера | Тренер |
| `DELETE /account/data` | Отключиться от сервера: удалить данные и сессии тренера | Тренер |
| `POST /crash` | Отчёт об ошибке без личных данных (с согласия) | Публично, лимит |
| `GET /app/latest?platform=android` | Последняя версия приложения | Публично |
| `GET /admin/coaches`, `POST /admin/coaches/{id}/suspend`, `/resume`, `/features` | Управление тренерами: приостановка, открытые возможности с датой «до» (этап 5) | Администратор |
| `GET /admin/status` | Диск, память, последняя копия и проверка восстановления | Администратор |
| `GET /c/{token}`, `POST /c/{token}/pin` | Кабинет (HTML) | Токен кабинета |
| `GET /health` | Проверка сервера и базы | Публично |

Настройки кабинетов (CabinetAccess) и данные клуба идут обычной синхронизацией: отдельных адресов для них нет. Записи с `scope = CLUB` сервер принимает только от администратора.

*Изменено на шаге 2.8 (24.10.2026):* регистрация открытая с подтверждением почты кодом (`/auth/confirm`), сброс пароля кодом на почту (`/auth/reset/request`, `/auth/reset`), «Выйти на этом устройстве» — `DELETE /me/sessions/{id}`; коды приглашения и код сброса от администратора отменены.
