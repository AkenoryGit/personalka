# 7.1. API

Раздел [7. Сервер и синхронизация](7.md) · [оглавление ТЗ](README.md)

REST + JSON, префикс `/api/v1`, авторизация — заголовок `Authorization: Bearer <токен сессии>`. Ошибка — `{"code": "invite_expired", "message": "Код приглашения истёк"}`, текст на русском для показа пользователю.

| Метод и адрес | Назначение | Доступ |
| --- | --- | --- |
| `POST /auth/register` | Регистрация по коду: `invite_code`, `email`, `password`, `display_name`, `device_name` → токен сессии | Код приглашения |
| `POST /auth/login` | Вход с другого устройства | Публично |
| `POST /auth/logout` | Завершить сессию | Тренер |
| `POST /auth/reset` | Новый пароль по коду сброса от администратора | Код сброса |
| `GET /me` | Профиль, роль, статус, список сессий | Тренер |
| `POST /sync/push` | Отправить изменения (до 500 за раз) | Тренер |
| `GET /sync/pull?since=&limit=` | Получить изменения после номера | Тренер |
| `DELETE /account/data` | Отключиться от сервера: удалить данные и сессии тренера | Тренер |
| `POST /crash` | Отчёт об ошибке без личных данных (с согласия) | Публично, лимит |
| `GET /app/latest?platform=android` | Последняя версия приложения | Публично |
| `POST /admin/invites`, `GET /admin/invites`, `DELETE /admin/invites/{id}` | Коды приглашения | Администратор |
| `GET /admin/coaches`, `POST /admin/coaches/{id}/suspend`, `/resume`, `/reset-code` | Управление тренерами | Администратор |
| `GET /admin/status` | Диск, память, последняя копия и проверка восстановления | Администратор |
| `GET /c/{token}`, `POST /c/{token}/pin` | Кабинет (HTML) | Токен кабинета |
| `GET /health` | Проверка сервера и базы | Публично |

Настройки кабинетов (CabinetAccess) и данные клуба идут обычной синхронизацией: отдельных адресов для них нет. Записи с `scope = CLUB` сервер принимает только от администратора.
