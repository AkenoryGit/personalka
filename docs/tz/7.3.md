# 7.3. Вход и сессии

Раздел [7. Сервер и синхронизация](7.md) · [оглавление ТЗ](README.md)

- Пароль — не короче 10 символов, хранится как Argon2id.
- Токен сессии — 32 случайных байта, на сервере только хэш; на телефоне — в защищённом хранилище (Android Keystore / iOS Keychain). Срок 180 дней, продлевается при каждом использовании.
- Вход: не больше 5 попыток в минуту на адрес почты и IP.
- Сброс пароля без почтовой рассылки: администратор создаёт одноразовый код сброса (24 часа), тренер вводит его и новый пароль.
- В настройках виден список устройств с кнопкой «Выйти на этом устройстве».
