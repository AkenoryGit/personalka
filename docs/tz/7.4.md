# 7.4. Развёртывание

Раздел [7. Сервер и синхронизация](7.md) · [оглавление ТЗ](README.md)

Рядом с Planovo, по той же схеме, но полностью отдельно:

| Что | Как |
| --- | --- |
| Служба | `trener.service` (systemd), пользователь `trener` с урезанными правами, Java до 384 МБ, перезапуск через 5 секунд, письмо при повторяющихся падениях |
| База | База `trener` в том же PostgreSQL, роль `trener` с доступом только к ней; доступна только с самого сервера |
| Адрес | `trener.planovo-app.ru` (решение 24.10.2026, шаг 2.7) через Caddy, сертификат выпускается сам; после первых ссылок родителям не меняется |
| Настройки | Файл окружения с правами только для службы |
| Миграции | Flyway при запуске |
| Выкладка | GitHub Actions: тесты → сборка → копирование по SSH → переключение версии → проверка `/health`; не прошла — автоматический откат. Ручная кнопка «Откат сервера» |
| Перед установкой | Проверить свободную память и диск; если свободной памяти меньше 600 МБ — увеличить тариф |
