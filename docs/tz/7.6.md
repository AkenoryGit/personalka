# 7.6. Резервная копия на телефоне

Раздел [7. Сервер и синхронизация](7.md) · [оглавление ТЗ](README.md)

- Файл `trener-backup-ГГГГММДД-ЧЧММ.zip`: все таблицы в JSON + описание (версия схемы, число записей, контрольная сумма).
- Шифрование паролем (AES-GCM, ключ из пароля через Argon2id) — включено по умолчанию, потому что в копии данные детей. Забытый пароль = недоступная копия; приложение говорит об этом при включении.
- Автокопия — в папку, выбранную системным диалогом (в том числе облачные папки, если приложение облака их предоставляет), в папке хранятся последние 10 копий. Вручную — «Создать копию сейчас» и «Поделиться».
- **Восстановление:** выбор файла → пароль → предпросмотр (дата копии, клиентов, тренировок) → подтверждение «Все текущие данные будут заменены». В режиме «С сервером» после восстановления данные целиком выгружаются на сервер и заменяют там старые.
- **Выгрузки для чтения:** Excel (листы «Клиенты», «Тренировки», «Результаты», «Зарплата по месяцам») и календарь .ics (прошлые 3 и будущие 3 месяца) — для просмотра в любом календаре.

**Шаг 1.15 (23.10.2026).** Как сделано:

- **Файл** — zip: `backup.json` (формат, версия схемы базы, время копии по клубу, число записей по таблицам, SHA-256 данных, параметры шифра) и данные — `data.json` или, с паролем, `data.bin`. В JSON попадают все таблицы базы как есть, кроме служебных таблиц SQLite и Room: новая таблица войдёт в копию сама.
- **Шифр** — AES-256-GCM, ключ — Argon2id из пароля: 19 МиБ памяти, 2 прохода, 1 полоса (параметры записаны в файле — следующие версии могут взять другие). Пароль — не короче 6 знаков, вводится дважды, с предупреждением «Забудете пароль — копию не откроет никто, даже разработчик». На телефоне хранится не пароль, а ключ из него: автокопия шифруется без вопроса, своя копия открывается без пароля. Шифрование можно выключить переключателем «Шифровать паролем» (по умолчанию включено).
- **Автокопия** — при открытии приложения и раз в час, пока оно открыто (без фоновой службы): если папка выбрана и последней копии в папке нет сегодня (или 7 дней — «Раз в неделю»). Частота — чипы «Каждый день» / «Раз в неделю», по умолчанию каждый день. В папке остаются 10 последних копий `trener-backup-*.zip`, чужие файлы не трогаются. Папка пропала или доступ к ней отозван — «Папка для копий недоступна — выберите её снова».
- **«Поделиться копией»** — системное «Поделиться» (мессенджер, почта, облако); такая копия тоже считается — «Последняя копия» и напоминание (1.5, 5.2) от неё.
- **Восстановление** — одной транзакцией: не вышло — данные прежние. Копия из более новой версии приложения не восстанавливается («сначала обновите приложение»); из более старой — по общим столбцам, новые получают значения по умолчанию. Пароль восстановленной копии становится паролем копий этого телефона. С шага 2.7б копия старой версии сначала проходит переходы базы (ТЗ 10.2) — пересчитанные ими данные не теряются; копия перед обновлением базы — тоже в формате 7.6, см. ТЗ 10.2.
- **Календарь .ics** — через «Поделиться» (в календарь телефона или себе в мессенджер): время в UTC, название «ПТ · Орлов М.», место — полное название, отменённые — со статусом «отменено».
- **Excel** — не в шаге 1.15: листов «Результаты» и «Зарплата по месяцам» ещё нет (дневник — этап 2, зарплата — этап 3); выгрузка — в шаге 3.8в (шаг 3.8 разделён 25.10.2026: листу «Зарплата по месяцам» нужен «Год» шага 3.8б). Выгрузка на сервер после восстановления — с режимом «С сервером» (этап 2).

**Шаг 3.8в (25.10.2026).** Выгрузка в Excel — как сделано:

- **Кнопка** «Выгрузить в Excel» в «Настройки → Данные», в блоке «Выгрузки» под календарём; файл `trener-data-ГГГГММДД.xlsx` уходит системным «Поделиться» — в Google Таблицы, Excel, на почту или себе в мессенджер (как .ics). Пароля нет: это выгрузка для чтения, а не копия.
- **Файл** — настоящий .xlsx (Office Open XML), собирается на чистом Kotlin без библиотек (подойдёт и iPhone). Числа, деньги и даты — числами с форматом («124 800,00», «22.10.2026»): их можно складывать и сортировать. Первая строка каждого листа закреплена.
- **«Клиенты»** — все клиенты, сначала занимающиеся, потом в архиве, по фамилии: ФИО, дата рождения, для связи, телефон, группы на сегодня, статус, сколько раз был на проведённых тренировках и последняя, ссылка на фото и видео, заметка «для себя» (файл получает только сам тренер, в кабинет заметка по-прежнему не попадает).
- **«Тренировки»** — все тренировки, прошлые и запланированные, по времени: дата, день недели, начало, минуты, тип, место, группа, клиенты (с отметкой «отмена» / «отмена со списанием»), статус, кто провёл («я», «я и Лена», «Лена»), причина отмены, план, факт.
- **«Результаты»** — дата, клиент, дистанция, стиль, бассейн, время «1:03,17» и оно же в секундах числом (63,17 — для сортировки и графика), где показан, старт, заметка.
- **«Зарплата по месяцам»** — те же месяцы и тем же расчётом, что вкладка «Год» (5.12): год, месяц, заработано, прогноз (у идущего), план, % плана, налог, на руки, ПТ, дети в группах, часы дежурств; после каждого года — жирная строка «Итого ГГГГ». Годы — с первой тренировки по нынешний. Поэтому суммы в файле совпадают с приложением до копейки.
