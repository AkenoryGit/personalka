# 7.7. Обновления приложения

Раздел [7. Сервер и синхронизация](7.md) · [оглавление ТЗ](README.md)

- **Android:** раз в сутки приложение спрашивает `/app/latest`. Новая версия → плашка «Доступна версия 1.3: что нового. Обновить» → загрузка APK с домена, проверка SHA-256, системный установщик. Версия ниже `min_supported` — блокирующий экран с кнопками «Обновить» и «Сохранить резервную копию». Позже — публикация в RuStore.
- **Ключ подписи APK** хранится в двух местах вне репозитория: без него нельзя выпустить обновление без переустановки.
- **iPhone:** TestFlight; новая сборка не реже раза в 80 дней (сборка действует 90).
- Миграции локальной базы выполняются при запуске; перед миграцией автоматически создаётся резервная копия.
