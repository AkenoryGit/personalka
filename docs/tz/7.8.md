# 7.8. Журналы и наблюдение

Раздел [7. Сервер и синхронизация](7.md) · [оглавление ТЗ](README.md)

- Журнал сервера — в journald, 14 дней, без личных данных и токенов.
- Письма администратору: повторяющиеся падения, сбой копии или проверки восстановления, свободное место на диске меньше 2 ГБ.
- Падения приложения сохраняются локально; при следующем запуске — предложение отправить отчёт (только технические сведения, без данных клиентов).
