# 8.1. Формат отчёта

Раздел [8. Сверка с 1С](8.md) · [оглавление ТЗ](README.md)

- Заголовок: ФИО тренера и «Отчет по тренировкам за период: 01.10.2026 - 31.10.2026».
- Колонки: Дата («дд.мм.гггг чч:мм»), Услуга («Персональное занятие» / «Групповое занятие»), Наименование услуги, Клиент (ФИО полностью), Статус («Пришел» / «Не пришел» / «Отменил»), Количество услуг, Клиентов, Стоимость. Одна строка = один клиент на одном занятии; сплит и группа — несколько строк.
- Ячейки многострочные: часть текста стоит выше строки с датой, часть — ниже.
- Названия услуг (октябрь 2026): «Персональная тренировка. ББ», «Персональная тренировка. Детский бассейн 45 минут», «Детская групповая тренировка в бассейне 50 минут», «Мини-группа ББ», «Сплит. ББ», «Стартовая тренировка бассейн».
- «Стоимость» — «2 200,00» с запятой, у отмен — «0.00» с точкой.
- Итоги: «Итого: 204 204 282 320», «Итого клиентов: …», «Итого занятий: 106» (выгрузка 18.10); за 1–25 октября — «Итого: 289 289 406 510», «Итого клиентов: Не пришло - 1, Пришло - 281, Отменило - 7», «Итого занятий: 154».
- Строка заголовка таблицы стоит не на каждой странице: на одних — вверху, на других — внизу, на третьих её нет (*уточнено 26.10.2026, шаг 4.1*).
- Имя файла содержит время выгрузки: `…report-20261018T104841.pdf`.
- Группы, которые числятся на другом тренере, в отчёт не попадают.
