# 8.2. Разбор PDF

Раздел [8. Сверка с 1С](8.md) · [оглавление ТЗ](README.md)

1. Извлечь текст с координатами каждого слова.
2. Найти строку заголовка таблицы по словам «Дата», «Услуга», «Наименование услуги», «Клиент», «Статус», «Количество услуг», «Клиентов», «Стоимость» и по ним определить границы колонок. Заголовок есть не на каждой странице — страница без него берёт колонки предыдущей; строки заголовка (и вверху, и внизу страницы) в ячейки не попадают (*изменено 26.10.2026, шаг 4.1*).
3. Якорь строки — слово в колонке «Дата» вида `дд.мм.гггг чч:мм`. Каждая остальная строчка текста привязывается к ближайшему по вертикали якорю той же страницы (граница — середина между соседними якорями, но не дальше 12 пт — так в строку не попадают шапка и итоги) и дописывается в свою колонку сверху вниз.
4. Остановиться на «Итого». Сверить число строк с первым числом после «Итого:»; не совпало — «Отчёт прочитан не полностью».
5. Проверить ФИО тренера с `Coach.name_1c`; другое имя — «Это отчёт другого тренера?».
6. Не нашли таблицу — «Это не похоже на отчёт 1С по тренировкам».

Проверено на отчёте за октябрь 2026: 6 страниц, все 204 строки извлекаются без ошибок. Этот отчёт становится тестовым файлом разборщика (в репозиторий — с заменёнными именами).

*Шаг 4.1, 26.10.2026:* тестовый файл — выгрузка за 1–25 октября (9 страниц, 289 строк, сумма 406 510 ₽ сходится с «Итого»), ФИО тренера и 76 клиентов заменены на придуманные. Текст с координатами читается своим кодом на чистом Kotlin (`shared/domain/report1c`: распаковка Deflate, шрифты с `ToUnicode`), без библиотек — подойдёт и для iPhone.
