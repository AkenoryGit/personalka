# 8.3. Сопоставление

Раздел [8. Сверка с 1С](8.md) · [оглавление ТЗ](README.md)

- **Имена.** Нормализация: нижний регистр, ё → е, лишние пробелы убраны; ключ — фамилия + имя, отчество не учитывается. Порядок поиска: сохранённая связь ClientAlias1C → точное совпадение ключа (если единственное — принимается само) → похожие (разница до 2 букв в фамилии при том же имени) на подтверждение → «Неизвестный клиент» (можно создать). Подтверждённая пара сохраняется.
- **Услуги.** По ServiceMapping1C; неизвестное название — шаг «Укажите тип и место для «…»», один раз.
- **Что из приложения сверяется:** участия клиентов в тренировках, где владелец — тренер, в периоде отчёта и с началом до времени выгрузки; дежурства не сверяются.
- **Пары.** Для каждой строки 1С — участие того же клиента в тот же день, ближайшее по времени в пределах 90 минут. Без пары — «Только в 1С»; участия без пары — «Только в приложении».
- **Статусы:** «Пришел» = `ATTENDED` или `CANCELLED_CHARGED`; «Отменил» и «Не пришел» = `CANCELLED`. Не отмеченная в приложении (`EXPECTED`) прошедшая тренировка — тоже расхождение. Другая услуга (в 1С сплит, в приложении ПТ) — расхождение «услуга».
- Деньги не сравниваются: «Стоимость» — цена для клиента, не оплата тренера.

*Шаг 4.2, 26.10.2026 — уточнения* (правила — `Reconcile1cRules` в `shared/domain/report1c`):

- **Имена.** Связь ClientAlias1C на удалённого клиента не действует — имя ищется заново. Несколько клиентов с тем же ключом (полные тёзки) — не «принимается само», а выбор из них, как у похожих; имя и фамилия наоборот — тоже похожий (как в 5.8, шаг 3.9о).
- **Время выгрузки.** Сверяются участия, начавшиеся до времени выгрузки из имени файла; в имени его нет — до момента сверки, но не позже конца периода отчёта.
- **Отмены без пары — не расхождение.** Строка 1С «Отменил» или «Не пришел» без участия в приложении и отменённое без списания участие без строки в 1С считаются совпавшими: денег за них нет ни там, ни там, исправлять нечего. Отмена со списанием без строки 1С — «Только в приложении».
- **Пары** подбираются от самых близких по времени: из двух тренировок клиента в пределах 90 минут строке достаётся ближайшая.
- **Услуга** сравнивается по типу и месту из ServiceMapping1C: в 1С «Персональная тренировка. ББ», а в приложении ПТ в детском бассейне — тоже расхождение «услуга».
- Строки с неизвестным клиентом или неизвестной услугой в пары не идут — это пункты `UNKNOWN_CLIENT` и `UNKNOWN_SERVICE` в списке «Только в 1С»; экран сначала просит указать тип услуги и выбрать клиентов (5.14), поэтому обычно их нет.
