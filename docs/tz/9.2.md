# 9.2. Правила преобразования

Раздел [9. Разовый импорт из таблиц](9.md) · [оглавление ТЗ](README.md)

> Импорт отменён 23.10.2026 — см. [раздел 9](9.md).

- **Статусы:** «Запланировано» → `PLANNED`/`EXPECTED`; «Проведено» → `DONE`/`ATTENDED`; «Отменено» → `CANCELLED`/`CANCELLED`; «Отмена со списанием» → `CANCELLED`/`CANCELLED_CHARGED`.
- **Время:** «10.00», «10:00», «9.30» → чч:мм; пустое — в отчёт проблем.
- **Тип и место** тренировок клиента — из файла сопоставления (клиент → тип, место), по умолчанию ПТ · ББ; длительность 50 минут.
- **Результаты:** «в/ст» → вольный стиль, «н/сп» → на спине, «брасс», «батт»/«дельфин», «к/п»/«комплекс». Время: «1.03,17», «1,14.75», «59.00», «52.16», «56,99 (50м бассейн)» — три группы цифр = минуты, секунды, сотые; две = секунды, сотые. Бассейн 50 м, если в скобках указано «50м», иначе 25 м. Неразобранное — в отчёт.
- **Группы:** Д → владелец я, провёл один; Д+Л → владелец я, вместе с Леной; Л+Д → владелец Лена, вместе. Постоянная группа = день недели + время + тип; состав = дети, приходившие за последние 4 недели. Все дети в списке — `ATTENDED`.
- **Даты с опечаткой года** (в листе «Октябрь группы» есть 2023 вместо 2026) исправляются на год листа и попадают в отчёт.
- **Имена детей** сопоставляются как в 8.3; похожие («Дельфенурова»/«Делфенурова») — предложение объединить в отчёте. Пол — по правилам 4.17, только однозначные случаи, остальные пустые; родственные связи не импортируются.
- **Постоянное расписание:** если у клиента тренировки в один день недели и время не менее 3 раз за последние 4 недели — создаётся серия со следующего дня после последней импортированной тренировки (список — в отчёте на подтверждение).
- **«Последние 4 недели»** (состав групп и серии) — 28 дней до последнего дня, который есть в таблицах и не позже дня запуска, а не до самого дня запуска: результат не зависит от того, когда утилиту запустили.
- **Строка с проблемой** (нет даты, времени или статуса, неразобранный результат, ребёнок без фамилии) не переносится, пока её не исправят: числа отчёта — ровно то, что попадёт в копию.
- **Итоги месяцев** утилита считает сама из строк дней, а не берёт из ячеек «ИТОГО»: в шести месяцах там суммируются дни только до 28-го.
