# 9.3. Месяц перехода

Раздел [9. Разовый импорт из таблиц](9.md) · [оглавление ТЗ](README.md)

> Импорт отменён 23.10.2026 — см. [раздел 9](9.md).

Задаётся первый месяц, зарплату за который считает приложение (по умолчанию — первый полный месяц после приёмки этапа 3; выбирается при запуске этапа 3). Для более ранних месяцев экраны зарплаты показывают ArchivedMonth с пометкой «из таблицы», а импортированные тренировки видны в календаре, карточках и кабинетах, но в зарплату не входят. Так ничего не считается дважды.
