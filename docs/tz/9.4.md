# 9.4. Порядок

Раздел [9. Разовый импорт из таблиц](9.md) · [оглавление ТЗ](README.md)

> Импорт отменён 23.10.2026 — см. [раздел 9](9.md).

1. Выгрузить все Google-таблицы в xlsx в одну папку.
2. Запустить утилиту в режиме проверки (`java -jar personalka-import.jar <папка>`; jar — в релизе «Последняя сборка» рядом с APK, нужна Java 21) → в папке таблиц появляются `отчёт-импорта.txt` (сколько клиентов, тренировок, результатов, групп, серий и список проблем) и `сопоставление.txt`.
3. Исправить проблемы в файле сопоставления (объединения имён, тип и место клиентов, месяц перехода) и повторить проверку до пустого списка. Файл сопоставления — текст с разделами «Месяц перехода», «Клиенты: тип и место», «Похожие имена» (`вариант → правильное = да / нет / ?`), «Серии» (`да / нет`); утилита переписывает его при каждой проверке, сохраняя значения тренера.
4. Собрать файл копии (с паролем).
5. На телефоне при первом запуске — «Восстановить из копии»; сверить числа с отчётом утилиты и выборочно трёх клиентов.
6. Удалить выгруженные файлы и файл копии с компьютера.
