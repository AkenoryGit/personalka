# 9.4. Порядок

Раздел [9. Разовый импорт из таблиц](9.md) · [оглавление ТЗ](README.md)

1. Выгрузить все Google-таблицы в xlsx в одну папку.
2. Запустить утилиту в режиме проверки → отчёт: сколько клиентов, тренировок, результатов, групп, серий и список проблем.
3. Исправить проблемы в файле сопоставления (объединения имён, тип и место клиентов, месяц перехода) и повторить проверку до пустого списка.
4. Собрать файл копии (с паролем).
5. На телефоне при первом запуске — «Восстановить из копии»; сверить числа с отчётом утилиты и выборочно трёх клиентов.
6. Удалить выгруженные файлы и файл копии с компьютера.
