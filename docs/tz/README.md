# ТЗ: приложение тренера «Персоналка»

Техническое задание на мобильное приложение тренера (Android, затем iPhone), сервер и веб-кабинет родителей. Версия 1.0. Основано на [документе требований](https://claude.ai/code/artifact/b4967de9-bbfd-4efd-bdb9-05cd4f9b193d); при расхождении действует это ТЗ.

Версия 1.0 от 18.10.2026 с правками шагов 0.1–0.8 (по 22.10.2026). С шага 0.9 главная копия ТЗ — эта папка: правки вносятся здесь, [документ ТЗ в Claude](https://claude.ai/code/artifact/be7cb823-3690-44c6-92cf-a63ca82d96a5) остаётся копией на 22.10.2026.

## Как читать

- Каждый подраздел — отдельный файл с номером в имени: ТЗ 4.16 — [`4.16.md`](4.16.md), ТЗ 5.3 — [`5.3.md`](5.3.md).
- Вступление раздела и список его подразделов — файл с номером раздела: [`4.md`](4.md).
- Этапы раздела 11 — файлы `11.0.md`…`11.5.md` («ТЗ 11, этап 2» — [`11.2.md`](11.2.md)). Разделы 12 и 13 — целиком в [`12.md`](12.md) и [`13.md`](13.md).
- Шаг плана читает только разделы, указанные у него в [`docs/plan.md`](../plan.md). Целиком ТЗ не читается.
- Ссылки вида «(4.16)» внутри текста — на подраздел ТЗ, то есть на файл `4.16.md`.
