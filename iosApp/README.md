# iosApp

Приложение для iPhone (iOS 16 и новее, ТЗ 2.3). Появится на шаге **5.1 «Сборка для iPhone»**: проект Xcode, iOS-сборки модулей `shared/*` и платформенные части на Swift — уведомления, файлы, разбор PDF через PDFKit.

До этого шага общий код в `commonMain` пишется только на общем Kotlin, без `java.*` и Android, — чтобы на 5.1 он собрался для iOS без переделок.
