# Утилита импорта таблиц

Разовый перенос Google-таблиц в «Персоналку» (ТЗ 9). Работает на компьютере; в приложении импорта нет.
Шаг 1.17 — **режим проверки**: утилита читает таблицы и пишет отчёт. Сборка файла копии для телефона — шаг 1.18.

## Как запустить

1. Нужна Java 21 или новее: [adoptium.net](https://adoptium.net) → Temurin 21 (LTS) → установить (для Mac — файл `.pkg`
   под ваш процессор: Apple M — aarch64). Проверка: в «Терминале» `java -version` — должно быть 21 или больше.
2. Скачать `personalka-import.jar` из релиза «Последняя сборка» — там же, где APK:
   `https://github.com/AkenoryGit/personalka/releases/download/latest-build/personalka-import.jar`.
3. Выгрузить все таблицы клиентов и таблицу зарплаты в одну папку: в Google-таблице «Файл → Скачать → Microsoft Excel (.xlsx)».
4. Запуск — любым способом:
   - **двойной щелчок** по `personalka-import.jar` → окно выбора папки с таблицами → итог в окне. На Mac при первом
     запуске система может не пустить файл из интернета: правый щелчок → «Открыть» → «Открыть»;
   - **из «Терминала»** (Mac) или командной строки (Windows):

     ```
     java -jar ~/Downloads/personalka-import.jar ~/Desktop/Таблицы
     ```

5. В папке с таблицами появятся два файла:
   - `отчёт-импорта.txt` — сколько клиентов, тренировок, результатов, групп, серий и месяцев зарплаты перенесётся, список проблем;
   - `сопоставление.txt` — тип и место клиентов, объединение похожих имён, серии, месяц перехода. Его можно править
     в Блокноте: утилита при следующем запуске сохранит ваши значения.
6. Исправить проблемы — в таблице (выгрузить заново) или в `сопоставление.txt` — и запускать снова, пока не будет
   «ПРОБЛЕМ НЕТ».

## Как утилита понимает таблицы

- **Файл клиента** — тот, где есть лист «Тренировки» или «Общая информация». ФИО — из листа «Общая информация»
  (подпись «ФИО»), а если его нет — из имени файла. Столбцы ищутся по заголовкам: «Дата», «Время», «Статус», «План»,
  «Факт», «Поведение»; в «Результатах» — «Дата», «Дистанция», «Время», «Тип». Порядок столбцов не важен.
- **Таблица зарплаты** — та, где есть листы «<Месяц> группы» или «Настройки». В листах групп — «Дата», «Время», «Тип»
  (Д, Д+Л, Л+Д) и дети: через запятую в одной ячейке или по одному в ячейках правее. Дата в объединённой ячейке
  относится ко всем тренировкам дня.
- **Месячные листы** («Октябрь», «Ноябрь 2026») — строка заголовка со столбцом «Дата»; итоги считаются по строкам
  дней, а значение из «ИТОГО» показывается рядом, если отличается.
- Если лист не понят, в отчёте будут его первые строки — по ним видно, что поправить в утилите.

## Для разработки

`./gradlew :tools:import:test` — тесты на придуманных таблицах; `./gradlew :tools:import:importJar` — jar в
`tools/import/build/libs/`. Правила разбора (статусы, время, результаты, группы, серии) — `ImportRules` в
`shared/domain/.../importing`, чтение xlsx — здесь.
